November 24, 2026 · Feature Update

主动消息 2.0 · 同一个人 The one who writes from the cloud is the one you chat with.

这一批改动都围着一件事：在云端给你发消息的角色，和你在私聊里聊着的角色，应该是同一个人。说话的长短和分寸、看到的聊天记录、心情的起伏，两边现在是对得上的。顺带把时间感、工具调用和几处细节也一起理了一遍。

主题主动消息 2.0 · 离开后消息 · MCP 类型体验改进 阅读约 4 分钟

本次更新概览

  1. 说话的分寸跟私聊一样：温度、回复长度、心象开关都跟着 API 设置走。
  2. 看到的聊天记录更准：译文、表情、世界书都按私聊的方式处理。
  3. 发完之后：心情跟着更新，没发出去的那条只提一次。
  4. 离开后消息和见面离开提醒：分得清你是怎么走开的。
  5. 时间感：隔着手机说话时，角色知道你那边几点。
  6. 工具：破坏性工具的云端开关、连不到时自动转本机、查东西更顺。
  7. 没开 2.0 的离开后消息：也能查记忆，你回来它就停。
  8. 换了 API，云端马上跟上。
01

说话的分寸，跟私聊一样

云端和本地，用的是同一套参数。

定时主动消息、离开后消息、见面离开提醒，这几种由云端生成的消息，现在用的温度、回复长度上限，以及思考（心象）开不开，都和私聊是同一套：角色设了自己的对话 API 就跟角色的，没设就跟 API 设置里的全局配置。同一个角色在两边说话的长短和风格是一致的。

所以 2.0 设置里不再单独设「最大输出长度」，统一跟随 API 设置。你不需要重新设置什么。

02

看到的聊天记录更准

云端读到的，就是私聊里读到的那份。

云端生成消息前会先翻一遍你们最近的聊天。这份记录现在和私聊用同一种整理方式：

  • 开过双语翻译的，记录里只留原文，译文不会混进去。
  • 开了表情识图的，角色能读到你发的表情是什么意思，不只看到一个名字。
  • 世界书按和私聊一样的文本去找关键词，条目更容易在你预期的时候触发。
  • 设了触发概率的世界书条目，每次到点都会重新抽一次。
03

发完之后

心情会变，旧账只翻一次。

私聊里角色每回一句，心情和内心想法都会跟着更新。现在定时消息也一样：角色开着情绪 buff 时，云端发出消息的同时会评估一次，结果随推送一起回来。

角色之前排的某条消息如果没能发出去，下一次开口时它会知道这件事。这件事只提一次：说过之后就算告诉过了，后面几条消息里不会翻来覆去地讲。

04

离开后消息和见面离开提醒

你怎么走开的，它是知道的。
  • 离开后消息会分清你是刚见完面、刚挂了电话，还是线上聊着聊着走开的，开口的说法各不相同。刚见完面没多久时，它会按刚分开的语气来说。
  • 见面离开提醒里，角色会按自己的性格决定怎么开口：可能直接问你去哪了，也可能装作不经意，先说说自己这会儿在做什么。
  • 开了 2.0 的角色，这时候还可以顺势约下一次。约出来的消息照样算进你给角色定的频率上限，不会越约越多。
05

时间感更准

两个人，两块表。

给角色设了自定义时区、而且和你不在同一个时区时，私聊、群聊和语音视频通话里，角色既知道自己这边几点，也知道你那边现在几点，不会拿自己的钟去猜你这会儿醒着还是睡着。云端的即时对话和定时消息也一样。

见面这类当面相处的场合不受影响：两个人本来就在一起，用不着报你那边的时间。

06

工具用得更稳 NEW

MCP、排程，还有查东西。

新开关：允许云端执行破坏性工具。MCP 服务器标为破坏性的工具（比如删除），在本机调用前会先弹窗问你；云端没法弹窗，所以这类工具默认不会在云端用。只有你主动打开这个开关，即时对话和定时主动消息里才会直接调用它们，本机聊天照旧先问你。默认关闭。

设置 → 扩展连接 → MCP 页签 → 管理服务器 → 允许云端执行破坏性工具

云端连不到服务器时，自动改在本机生成。如果你的 MCP 服务器或小红书服务器装在自己电脑上、云端访问不到，这一轮即时对话会改在本机生成，输入框上方会出现一条提示，写明原因。服务器要能从公网访问，云端才用得上它。

排程更稳。关掉「原生 tools 工具调用」开关以后，角色照样能安排主动消息，改用文字写法。本机聊天时如果中转站不支持工具调用，会自动换成文字写法再试一次，不会直接报错；云端那边，用这类中转站时把这个开关关掉就行。

查记忆、搜索、翻日记、看小红书也顺了一些：

  • 同一轮里要查好几样东西，会一起去查，第二件不会漏掉。
  • 查到最后一轮会自然收尾，前面说过的不用再说一遍，不会硬凑一句重复的话。
  • 角色查完回来接着说时，不会把前面已经做过的转账、评论又做一遍。如果是故意在同一句里连着做几次，比如连发好几个一分钱红包，会照做。
  • 连着查好几轮时，中间那几轮说的话也会显示出来，不会被下一轮盖掉；查东西之前那句里的戳一戳、转账这类动作也照常生效。
07

没开 2.0 时的离开后消息

本机补的那几条，也更像样了。

没开主动消息 2.0 的角色，离开后消息是你下次打开 App 时在本机补上的。现在补的时候，角色会真的去查记忆、搜索、翻日记，和私聊里一样。

补到一半你回来开口了，它就停下，已经写好的那几条留着，后面的不再冒出来，不会出现你说完话它又补一句的情况。

08

换了 API，云端马上跟上

你亲手改的，以你为准。

在设置里亲手保存 API、或者切换 API 预设之后，云端会立刻改用新的配置，下一条主动消息用的就是你刚选的模型。

09

需要你做的

多数时候什么都不用做。

这些改动有不少落在你自己的 Worker 上。用「在 SullyOS 里装」装的 Worker，或者已经补过更新钥匙的，会自己定期更新，打开 App 时也会顺手查一次，一般什么都不用做。

没看到新表现时

手动部署、还没补更新钥匙的，或者想马上换上新版的，去 设置 → 主动消息 2.0 → 功能设置 → 后台地址与维护，点一下更新按钮。有新版时它是绿色的，写着「更新 Worker 到 …」；平时是浅色的「重新检查并更新 Worker」。

不管从哪边来，都是 ta。
