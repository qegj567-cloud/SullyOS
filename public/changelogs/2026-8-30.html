01

沉浸式与中度协同TWO CONTEXT MODES

沉浸式协同沿用 ChatApp 的完整角色上下文和最近聊天，最像刚从日常聊天一起走进工作间；中度协同只保留核心人设、你们是谁和最多五条相关记忆，更省上下文、更专心办事。

每个协同窗口彼此独立。新建窗口不会读到旧窗口的对话，默认也不会写进角色记忆。
02

文件不再只是“模型说做好了”REAL FILE DELIVERY

  • 上传并读取 Word、PDF、Markdown、JSON 等资料。
  • 将正文真正生成为 DOCX、PDF、HTML、TXT 等文件。
  • 文件点击后优先拉起系统分享；不支持分享的浏览器才回退下载。
  • 顶部文件夹可查看当前角色全部协同文件；点击分享，长按删除。

同一文件只保存一份。角色把它发送到日常聊天时只是引用原文件，不会悄悄复制第二份；因此在文件库永久删除后，聊天中旧的文件卡也会失效。

03

边聊边制作，再预览与安装MAKERS & INSTALLATION

首批支持气泡、白框、当前界面、日记本、日程卡、心象卡、角色卡和酒馆格式世界书。选择什么才注入什么制作规范，不会把全部提示词一次塞给角色。

作品完成后可以先全屏预览，再选择应用位置或挂载角色；生成内容还会经过字段、选择器和作用域检查，避免一段错误 CSS 把整个 App 锁死。

04

与日常聊天保持一座窄桥CHAT BRIDGE & MEMORY

可选择开启“当前聊天的有限协同桥接”：角色会知道文件柜中已有的文件，也能把准确文件作为正式附件发给你；但不能在日常聊天中假装现场制作 Word、PDF 或美化作品。

归档协同窗口时，会单独询问是否总结进记忆。选择后只写入一条日期范围总结；开启记忆宫殿的角色会同时在宫殿与神经链接各保存一份。

05

备份现在也带走协同工作BACKUP & RESTORE

设置 → 导出 与 设置 → 导入 已纳入协同窗口、消息、分类、独立 API 设置和文件本体。完整备份可跨设备恢复全部协同资料；纯文字和纯媒体档位仍遵守各自边界。

完整/纯文字备份包含协同 API 密钥，仍属于私人备份，不要发给别人。
