# 快捷导航与返回

「悬浮球设置」与其他设置板块一样默认折叠，展开后显示开关和 App 槽位。从悬浮球的「自定义」或空槽位进入时，自动展开并滚动到此板块；收起板块不改变已保存的开关或槽位。

设置内的「悬浮球复位抢救」只移除位置记录，并即时将已显示的球放回容器右下方的默认安全位置、收起菜单、结束拖动；保留开关和 4 个槽位。关闭状态也可复位，下次开启按默认位置显示。存储不可用时至少复位当前页面。独立的一次性「悬浮球来了」公告排在已有更新队列最前面，沿用数据就绪／解锁／启动提示的门禁；只有关闭、知道了、去设置才标已读，去设置定位并展开本板块，不自动开启球。公告不引入网络请求或新的启动等待。

设置顶部提供「悬浮球设置」，默认折叠，悬浮球开关默认关闭。开启后在未锁屏的界面显示：拖动调整位置，点开中央深色九宫格面板，包含「API 配置」「上一级」「桌面」、4 个自定义槽位、「自定义」和「收起」。设置也是可选槽位，不占固定按钮。槽位通过分层搜索选择器配置，可留空；空槽位和「自定义」都定位到悬浮球设置。使用桌面 App 清单，排除开发专用入口，不暴露隐藏／旧入口。开关、位置、槽位只保存在本机独立 localStorage key，不修改主题包、聊天或主库 schema。关闭时不挂载拖动、尺寸观察或展开菜单的监听；配置槽位不提前加载对应 App，只有点击才导航。

`utils/settingsNavigation.ts` 用进程内请求将「API 配置」定位到设置的折叠区域，展开后滚动；设置尚未挂载时保留一次请求，已经打开时直接处理。不重载设置，不重置 API 草稿，也不读写 API 凭据。深色面板在容器安全区居中，矮屏可滚动，减少运动设置下关闭展开动画。

悬浮球在拖动开始时读取容器边界和安全区，移动过程不做 DOM 尺寸读取，不写存储；结束时保存位置。重新开启、窗口大小或键盘导致容器尺寸变化时重新约束位置。音乐悬浮球保持原有播放控制用途。

槽位以 App ID 和可选的稳定目标 ID 保存。小屋支持 `room`（小小窝）、`worldHome`（家园世界）、`home3D`（拜访 3D）；前后两项可指定角色，中间可指定世界；Message 和神经链接可指定角色，所有分层入口也可只打开首页／列表。原 v1 的三个 App 字符串兼容读取为入口对象，第 4 个槽位补空，不改主库 schema。显示名仅作提示，路由始终按 ID；已删除角色提示重新配置，已删除世界回到家园列表，不改投其他目标。

其他入口按 `utils/navigationShortcuts.ts` 的目录展示，必须有对应 App 接收逻辑才加入目录：

- 神经链接：设定、记忆、印象、门牌、手办柜、统计 → 角色。
- 电话：通话准备 → 角色，或通话记录；不自动拨号，进行中的通话不会被快捷入口切换。
- 见面：准备、设置、记录 → 角色，或剧情剧场；准备入口不清除已有见面存档，不生成开场。
- 查手机：手机桌面、聊天、通讯录、通话、购物、外卖、朋友圈、智能体、人生模拟、生活记录 → 角色。
- 记忆宫殿：房间、像素家园、全部记忆、记忆盒、角色设置 → 角色，或全局设置；不自动启用宫殿。
- 交换日记、自习室、自由活动、攻略本、相册可选角色；分别进入日历、指定助教的书架、角色主页、攻略准备和相册。
- 音乐：主页、搜索、播放页、设置，以及角色音乐角落 → 角色；不自动播放。
- 群聊、世界书可选已有群组／条目；笔友会可选书稿、角色创作档案或新建；写歌可选乐谱或指定伙伴的新建表单。配置时只投影内存中已有的标题和 ID；删除的目标提示并回原 App 列表，不换成其他内容。
- 外观、存钱罐、Spark、时光契约可选现有标签页；彼方可选大厅、图书馆、普通房间、SAR 和设置。房间直达不邀请角色执行活动，也不调用生成接口。

`appShortcutLaunch` 在进程内传递请求，按 App 消费一次，支持 App 已打开时的重复导航；React StrictMode 不重复应用请求。异步读取通过当前请求标识拒绝已退出／后续快捷请求的旧结果。不同 App 之间不串目标，不通过强制重挂载来清空 App。没有细分导航的 App 保留直接打开入口。`entryId` 只接受目录中的枚举，角色和内容 ID 只允许匹配的目标类型；显示名不能影响路由。

`NavigationSlotPicker` 点击槽位才懒加载，支持 Unicode 宽度／大小写归一化、多关键词搜索和延后过滤；固定 68px 行只挂载可见区域和少量缓冲，不加载角色头像或 3D 预览。世界列表仅在选择家园分区时读取，失败可重试，取消或返回不写槽位。选择器打开时暂时隐藏悬浮球，避免挡住搜索框，关闭后恢复原位置。`roomLaunch`、`characterLaunch` 支持已挂载 App 订阅；3D 跳转仍走原入住定义／形象检查，不走 2D 房间初始化。选入口本身不生成房间、不请求模型，点快捷入口后保持原 App 的进入行为。

「返回上一级」、浏览器返回、Android 返回共用 OSContext.handleBack。「回到桌面」直接使用 closeApp。美化页面通过 useLocalBackHandler 接入：先处理打开的确认窗、预览或编辑面板，再返回装扮列表／外观设置；只有 App 顶层才走关闭 App 的默认逻辑。保存或领取进行中继续遵守已有的禁止退出条件。

局部返回层级：装扮入口 20、编辑或分享子页 30、导入预览 35、装扮预览 40、确认窗／预设选择器 60。子层比父层高；相同层级按最近挂载顺序处理。hook 用最新回调但保持注册顺序，卸载后移除自己，不覆盖其他面板。没有处理者时仍执行原 App 返回处理及关闭逻辑；普通外观标签不是嵌套子页，保持原有返回行为。

选择器打开和切换层级只聚焦对话框，不自动聚焦搜索；父组件更新回调不重新抢焦点。用户主动点搜索才开始输入，收起按钮、键盘完成键（输入法组合中除外）、点击搜索区域外可退出输入并保留关键词。全局返回／Escape 在搜索聚焦时先退出输入，随后返回才处理层级／关闭。关闭恢复原按钮焦点，避免重新聚焦编辑框而唤起键盘；Tab 焦点仍限制在弹窗内。
