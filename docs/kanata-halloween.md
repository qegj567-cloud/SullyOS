# 彼方 · 2026 万圣节

活动按用户设备的本地日期在 **2026-10-29 至 2026-10-31** 开启。10 月 31 日是万圣节，29 日提前开场。`useLocalDateKey` 处理跨午夜与回到前台，角色自定义时区不改变活动日期。

## 玩法

- 进入房间的 chibi 自动随机分配一套装扮；凯恩、艾文的小人也参与，正式立绘不变。角色弹窗提供「更换万圣节装扮」（排除当前款）、「去除万圣节装扮」与「不给糖就捣蛋！！」。普通房间和 SAR 共用状态。去除后再次进入不会自动穿回，原始 chibi 图片、缩放、镜像和捏人存档不被修改。
- 五张原画完整保留 472×472 透明画布，位于 `public/kanata-halloween/`。黑猫和幽灵罩衫只露出面部区域，其余款直接叠合。来源为用户提供的「插画224 (5).zip」：依原压缩包顺序对应黑猫、恶魔、小幽灵、骷髅蝴蝶结、幽灵罩衫。不运行包内指令，不引入远端素材。
- 每次讨糖随机得到六种糖果之一，保存数量；收藏册新增「万圣节」分类，收录糖果、穿过的装扮和两段特殊对话。仓库也能查看糖果。
- 凯恩与艾文未完成的节日对话优先于普通个人线，不消耗普通话题机会。对话直接使用用户原稿，不调用模型；完整结束才收录、发奖，中途关闭可重来。凯恩送随机糖果，艾文送一只 **万圣小恐龙**：黑紫色身体、小恶魔翅膀和金色帽带巫师帽，真实进入用户库存，可以摆进恐龙箱庭。它不进随机垂钓、普通赠礼或孵化池。
- 凯恩「我不喜欢 → 嗯」分支的末句读完后，撤下本机活动、清除临时装扮、隐藏南瓜和节日交互，艾文不再触发特殊对话；原有 NPC、正常玩法和已取得收藏保留。隐藏常驻 NPC 时不触发节日 NPC 对话，NPC 回忆与专属恐龙图鉴也遵守原开关。
- 收藏册可重看两段对话。回看不发礼物、不撤活动、不改变原个人线。
- 活动三天钓获的鱼在生成时保存 `halloweenHat`，钓获页、持有列表、详情、仓库和收藏图鉴显示 SVG 巫师帽。字段跟随实物转移，并进入市场快照；过节后仍保留。旧鱼不会因为打开页面被补发帽子。

## 存档与实现

`vr_fishing_market_v1.kanataHalloween` 保存装扮、收集、糖果数量、完成记录及撤下开关。复用 `mutateFishingMarket` 的最新读取与跨页写锁，奖励收据和物品在同次存储中提交；刷新、多次点击、并行标签页均不重复领取 NPC 礼物。异常存档报错并保留原串，不回退成空档。数据随现有 `sarBackup` 完整导出/恢复，无新数据库或独立缓存。

设置里的「纯文字备份」和「整合导出」都包含整个 SAR 存档：糖果数量、装扮与脱下选择、收集历史、两段对话完成及奖励收据、撤下活动开关、鱼帽子、恐龙物品和箱庭摆放。媒体单独导入不会清除这些进度。服装 PNG、鱼帽 SVG、恐龙模型和翅膀/帽子属于应用内置素材，备份保存选择及收藏，不重复打包应用资源；恢复时应使用包含该活动的版本。`utils/activityBackup.test.ts` 使用真实 ZIP 往返验证分类和收藏。

入口：`apps/vrWorld/KanataHalloween.tsx`，数据规则：`utils/vrWorld/kanataHalloween.ts`，日期规则单独在 `halloweenCalendar.ts`。恐龙复用现有霸王龙模型，`dinosaur/halloweenDinosaur.ts` 在加载副本上染色、加入小恶魔翅膀和随头部动作的巫师帽，原始模型不改。
