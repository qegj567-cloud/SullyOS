# 聊天站内相机

界面强调色使用系统 `--primary-hue`、`--primary-sat`、`--primary-lightness`，选择态和浅底随主题更新；不改变合成照片、滤镜或相框颜色。

拍立得式相框提供迷你白、迷你樱粉、方形白、方形黑。纸张宽高比为 mini 54:86、square 72:86，目标照片窗口为 46:62、62:62；非匹配比例的照片完整缩放到窗口内，增加留白而不裁掉人物。预览与导出共用 `cameraFrames`，拖动坐标扣除纸边并映射回照片区域。

Live2D 静态快照在读取瞬间以 1024px 长边重新渲染，再恢复实时预览密度，避免把 160x200 小预览直接放大。发送仍沿用 600px/0.6 JPEG 压缩参数：`processImageToBlob` 使用临时 object URL 解码、`toBlob` 压缩，再通过 `putImageBlobDeduped` 直接保存，消息和相册共用一个短引用。中间不再转 base64；解码或存储失败提示错误，不回退保存 base64，不额外持久化高清原图。GIF 沿用原文件字节。聊天图片点击打开 `ChatImage` 大图层，支持放大、保存按钮，并保留原生图片长按菜单；保存的是现有消息图片，不宣称能还原上传原图。原生长按保存的菜单名称和可用性由移动浏览器决定。

## 素材许可边界

基础滤镜和溶图为本项目实现，未导入 Shoost 的代码、LUT 或素材。角色图片、Live2D 模型仍受各自授权约束，能加载不等于允许再分发或商用。内置装饰已替换为固定的 Fluent PNG，不再依赖系统 Emoji 字体输出。

已接入 [Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji) 的 8 款 MIT 立体贴纸、[Kenney Particle Pack](https://kenney.nl/assets/particle-pack) 的 3 款 CC0 透明光效（screen 合成），均按需读取本地资源，支持拖动、旋转、缩放和不透明度。完整许可及固定来源记录位于 `public/assets/camera/` 和 `public/licenses/camera.html`，界面可打开许可页，Vite 构建会随静态资源分发。项目本身的许可不变。

进阶镜头色散与微缩移轴使用 `pixi-filters@6.1.5`（MIT，兼容现有 Pixi 8），按子路径引入并在强度非零时动态加载 WebGL 渲染器，不启动动画循环。每轮输出取消过期异步结果，处理期间禁止发送，卸载销毁 GPU 资源；初始化失败保留基础滤镜并提示。移轴为固定中心焦带，不做人物分割。整图特效完成后再绘制相框，原图对比不参与导出。

## 备份与统计

- 设置的完整备份包含压缩成片对应的 `messages`、`galleryImages` 和 blob 二进制；媒体备份也包含这些图片，文字备份按原约定剥离图片。导入复用原有图片恢复流程，不另存原片、贴纸图层或滤镜工程。
- 自定义贴纸上传、Live2D 截图、溶图缓存与滤镜参数都是当前编辑器的临时状态，关闭即释放，不属于用户备份数据；内置贴纸与许可随应用部署。
- `chatShowRemark` 随完整/文字备份的角色资料保存与恢复；媒体备份不覆盖角色文字设置。记忆自查的本机已读标记不迁移，换设备可重新提醒，月份开关本身仍随角色资料备份。
- Umami 仅记录固定功能分类，每次打开编辑器同类最多一次，不按发送消息计数，不记录图片、文件名、角色信息、模型地址或滑块数值。备注显示开关进入现有角色设置会话快照。
- CCD 是模拟便携数码相机色调的滤镜，包含冷暗部、暖高光、颗粒与轻微暗角，不代表特定传感器复刻。

## 使用流程

贴纸区「上传图片」支持 PNG/JPEG/WebP/GIF/AVIF（单文件不超过 20MB，动图截为解码时的静态画面）。透明通道保留，复用贴纸缩放、旋转、不透明度和溶图；只在当前编辑会话中使用，发送后仅保留压缩合成图，不保存上传素材。读取完成或失败均释放临时 objectURL，可重复选择同一文件，所有来源合计上限 12 张。

聊天功能面板的「相册」先选择「拍照」或「从相册选择」。前者使用 `getUserMedia` 获取摄像头画面，后者沿用系统文件选择器。

站内取景框跟随物理持机方向：竖持 3:4、横持 4:3；初次开启优先请求对应方向的分辨率，换方向通过现有轨道 applyConstraints 调整，不重新申请相机。默认请求 `resizeMode: none`，兼容重连时取消该偏好。浏览器仍返回不同宽高比时，取景框内完整等比显示并留空，不强行旋转或裁成 3:4；拍摄保留实际视频全部视野。多摄像头设备可手动选择浏览器公开的镜头；切换前/后置时清除指定镜头。硬件提供 zoom 能力时按真实范围调整并初始化到可用的 1×，调整变焦保留当前镜头和分辨率约束；否则提供 1–3× 数字缩放，预览与拍摄共用中心裁切。拍下后方向固定，长边最多 1440，不放大来源。

相机流由 `utils/cameraPreview.ts` 统一持有：未决权限请求串行，快速重试/切镜头只保留最新意图，过期请求返回的流立即释放；关闭时移除监听、停止所有轨道并断开视频元素。显式设置 muted/playsInline 后播放，只有活动且未 mute 的轨道和已解码的视频尺寸才能启用快门。启动即结束、持续 mute、没有首帧、NotReadable/Overconstrained/Abort 错误最多兼容重连一次（降低理想分辨率并短暂等待）；拒绝权限/没有设备不自动重试。短暂 mute 等待 unmute，不直接报永久断开。后台/pagehide 释放镜头，回前台/pageshow 只在仍处于取景时恢复。该处理不保证修复所有 iOS 系统摄像头故障，需要用户真机复测；不涉及数据库修复。

测试：`utils/cameraPreview.test.ts`、`utils/cameraCapture.test.ts`。浏览器无硬件测试页：`test/fixtures/chat-camera.html?synthetic=1&interruptedStart=1`，第一条模拟流已结束，后续流可正常预览，用于验证启动重连、切镜头与拍摄。

- 拍摄与编辑只保存在内存中；确认发送时生成 JPEG File，复用 `Chat.handleImageSelect` 的压缩、发送与糯米机相册落库流程。不调用系统相册写入、下载或系统分享接口。系统文件选择器中提供的拍照行为仍由设备控制。
- 站内相机需要 HTTPS（本地 localhost 除外）、浏览器摄像头支持与用户授权；失败展示原因和重试入口，不自动跳转到系统相机。
- 拍完、关闭、切换镜头、进入后台或切换聊天角色都会释放摄像头。权限请求晚于弹层关闭返回时也会立即停止新流。
- 相框、表情贴纸、彼方 chibi、手办柜（小小窝与 520）、DateApp 的基础立绘和各皮肤表情、Live2D 快照统一绘制到预览 canvas，发送的就是该合成画面。贴纸支持单指拖动、双指围绕手指中点缩放与旋转（可同时移动），抬起一根手指后可以继续拖动，不跳回旧位置。保留大小/旋转滑杆和删除，最多 12 个。
- 素材列表走 `cameraStickerSources`：各槽位独立列出，当前见面皮肤优先，所有立绘排除混装字段 `sprites.chibi`，不把头像冒充专属 chibi；520 已保存活动图优先于工坊待用图。兼容 blobref；远程图片必须支持跨域读取。Live2D 只在打开角色预览时懒加载，复用透明快照接口和服装配置。
- 「匹配环境光」仅在确认照片时为选中角色贴纸开启，默认关闭，可调溶图强度与边缘光。原照片缩小后生成低频光色场，按亮度分位数区分暗部与亮部、抑制孤立高亮点，在线性 RGB 中做有限曝光匹配、暗部乘色、亮部柔和滤色及高光压缩。根据背景亮区重心和贴纸 alpha 轮廓补可选边缘光；这是方向性近似，不代表识别了真实光源或三维表面。
- 背景光场与原始贴纸像素缓存；编辑阶段用最长边 256px 的贴纸缓存计算溶图，发送时才使用原贴纸完整计算。单个贴纸的溶图结果按位置、尺寸、角度、强度缓存；手势期间复用上次结果，最后一个指针松开或取消才刷新光照。素材 Blob 直接解成临时 object URL，读取后释放，不再转 base64。不改 alpha、角色原素材或数据库形象。
- 贴纸拖动与双指手势按动画帧合并更新，复用照片缩图与合成画布；手势中预览长边最多 360px，平时最多 720px，屏幕显示尺寸保持不变。滑杆变化的重绘也按帧合并。松手、取消或失去指针捕获时保留最后坐标。确认发送时重新合成完整照片（含完整贴纸光照、滤镜、特效和相框），期间锁定编辑，不把低分辨率预览当成片发送。
- 整图滤镜提供原色、清透、樱粉、夕照、胶片、黑白，可调强度；VFX 提供高光阈值柔光、确定性颗粒、暗角。顺序为原照片 → 角色溶图与贴纸合成 → 整图滤镜/VFX → 相框。柔光只扩散亮区，不模糊原图细节；颗粒的固定噪声保证预览与导出一致。眼睛按钮按住显示原照片，重置按钮只重置滤镜与 VFX。

设计参考：[VTube Studio Display Light Overlay](https://github.com/DenchiSoft/VTubeStudio/wiki/Display-Light-Overlay)、[Live2D Multiply/Screen Color](https://docs.live2d.com/en/cubism-editor-manual/multiply-color-screen-color/)、[Shoost 作者的分层调色与边缘光示例](https://www.patreon.com/MuRo_CG/posts/shoost-v0-10-0-87407825)。采用自有二维像素处理，不依赖这些软件，不声称复现其内部算法；没有三维法线、投影、景深识别或遮挡重建。

实现：`components/chat/ChatCamera.tsx`、`utils/cameraLighting.ts`、`utils/cameraPhotoEffects.ts`、`utils/cameraStickerSources.ts`。验证：对应 utils 单测与 `scripts/test-chat-camera.cjs`（Playwright 模拟摄像头，默认 Edge；可用 `CAMERA_QA_BROWSER`、`CAMERA_QA_URL` 指定环境）。

无外网的验证环境可设置 `CAMERA_QA_SKIP_LIVE2D=1`，明确跳过依赖在线模型的 Live2D 用例；其余拍照、贴纸单/双指手势与预览尺寸、完整分辨率发送、滤镜用例照常执行，不代表 Live2D 已验证。

隐私边界：继续使用站内 getUserMedia 拍照，不改用 input capture 调起系统相机。预览和未发送照片只存在当前编辑会话内存，关闭释放摄像头与临时内容，不写文件、不触发下载或系统相册保存；确认发送后才沿用糯米机聊天与相册的本机 IndexedDB 保存流程。用户主动保存图片仍沿用原入口。
