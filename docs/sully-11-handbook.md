# Sully-11 内部使用手册

每个二级标题是一页。竖线后是用户可能用的叫法，只供本机检索。「能力」一行构成常驻功能目录；其余各行是按需读取的操作规则。箭头表示从左到右操作或发生的结果；“若 / 需要 / 只有”后的条件决定走哪一步。涉及用户自己的开关时，以本轮设置摘要为准。

## Message | 聊天 | 私聊 | 不回 | 没回复 | 发消息 | 发完消息 | 闪电 | 自动回复 | 回车 | 表情包 | 输入框 | 生成按钮
能力：发送与闪电、合并收藏、转账、协同工作
核对：[Chat.tsx](../apps/Chat.tsx)、[conversation-favorites.md](conversation-favorites.md)、[collaboration-chat-bridge.md](collaboration-chat-bridge.md)
发文字 → 先入聊天记录；要角色接话 → 点标题栏的闪电按钮。＋ → 设置 → 输入与发送 → 保存，输入习惯对本机私聊及群聊共用。
自动回复开 + 发出消息 + 无草稿 + 输入框失焦 + 面板关闭 → 约两秒后生成；继续打字会推迟。开启「发送键代替生成键」→ 有光标时发送，点空白失焦后同一键生成。
收藏一整段对话 → 长按消息 → 多选 → 选中原话 → 合并收藏。收藏保存当时的快照；之后编辑或删除原消息仍能读快照。想回原处 → 从收藏跳回聊天，须原消息仍在。
转账(金额、备注) → 发出转账卡 → 收款方领取或退回 → 聊天出现对应回执。要改背景、气泡或译文样式 → ＋ → 聊天装扮。
在「聊天装扮 → 白框 → 内置白框」选择「银晕」并确认角色，即可使用银灰切角气泡和淡星影功能菜单。双方的消息时间显示在各自头像下方。「我的搭配 → 布局 → 时间位置」可单独更换时间的位置。
一起处理文档 → ＋ → 协同工作 → 在工作窗口处理材料；选中本窗口消息转发后才进私聊。允许协同读取的聊天范围可单独调，空范围不会读取整段私聊。
点过生成仍无回复 → 有 HTTP 报错查「接口排查」；裸标签、只剩心象查「掉格式」；想看这一轮带了哪些旧话查「记忆宫殿」。

## 接口排查 | API | 红色弹窗 | 不回 | 401 | 403 | 429 | 余额 | 超时 | 模型列表 | 白屏 | 连接失败
能力：报错自检、模型权限、限流、超时、按用途查错
核对：[api-call-log.md](api-call-log.md)、[character-api.md](character-api.md)、[StatusBar.tsx](../components/os/StatusBar.tsx)、[errorSelfCheck.ts](../utils/errorSelfCheck.ts)
状态栏「查看报错」→ 打开「报错自检」，先看哪项操作失败、建议查哪套配置；需要原文再展开「技术详情」。查看后本次提醒消失，日志仍可回看；新错误会再次提醒。复制全部日志若失败，可在文本框手动复制。
发完消息没有触发生成 → 先查输入设置。已经生成过 → 设置 → API 调用记录 → 找对应 App、用途和发生顺序。先区分主回复、副 API、向量化、语音；语音和向量化有自己的接口。
401/403 → 核对这次实际使用的凭据、模型权限；429 → 看服务商返回的限流或额度说明；上下文超限 → 核对输入原文范围和输出额度。单凭红窗不能判断欠费。
拉不到模型 → 核对所选接口类型、服务方给的地址和模型；地址是否要 /v1 取决于服务。白屏且还没发请求 → 问是整个桌面还是单个页面，记录复现动作，不建议清浏览器数据。
主对话正常但角色单独失败 → 看角色是否用了独立 API。App 独立配置、角色配置、全局配置按该功能的路由选整套凭据；一次测试成功只证明被测接口当时可用。

## 掉格式 | 格式 | 标签 | 裸指令 | 原样 | 卡片没出来 | 双语 | 译文 | 心象 | 思考 | 空正文 | JSON | HTML | 乱码
能力：原样指令、卡片未渲染、思考漏出、空正文
核对：[thinking-response.md](thinking-response.md)、[chat-translation.md](chat-translation.md)、[chatParser.ts](../utils/chatParser.ts)
先问「在哪个 App？本来该出现什么，实际显示了什么？」看用户自愿描述的一小段去隐私示例就够。
应出表情、转账、语音或双语气泡，却显示方括号指令、标签正文或残缺 JSON → 疑似模型输出不符合该入口协议。核对功能和角色开关、标签闭合、回复是否在中间截断。不同 App 的指令不能互用。
例：私聊显示“[[SEND_EMOJI: 抱抱”且回复在这里结束 → 查截断与表情名称；有文字却没译文 → 先查所选角色双语开关和输出是否包含完整原文/译文；HTML 模式关 → 不应预期富卡渲染。
只有心象 → 看是否另有回复正文。明确的思考字段或思考标签走心象；思考不能补作正文。普通英文、括号动作、外语对白本身都不能证明掉格式。
一直转圈或 HTTP 报错 → 查请求。内容完整但字看不见/输入框按不到 → 查聊天装扮或对比度。仅凭一次现象不要断定是模型坏了；先用同一入口的一条短消息验证。

## 记忆宫殿 | 记忆 | 忘了 | 失忆 | 不记得 | 水位 | 原文范围 | 归档 | 门牌 | 向量 | embedding | 断点 | 小眼睛 | 召回
能力：原文断点、月度精炼、自动整理水位、门牌召回
核对：[memory-system-overview.md](memory-system-overview.md)、[MemoryPalaceApp.tsx](../apps/MemoryPalaceApp.tsx)
「我明明聊过」→ 先区分聊天里还能翻到、这轮带了原文、已经整理成长期记忆三件事。私聊、通话、见面共享该角色允许的上下文；群聊另有公共记录，独立玩法按各自规则回传。
查原文 → 私聊「＋ → 设置 → 上下文与记忆 → 查看原文范围 / 设置用户断点」。手动 = 最近设定条数；自适应 = 成功整理的水位之后；用户断点再收窄范围。退出范围仍可在聊天里翻看。
传统档案 → 神经链接 → 角色 → 记忆。月度精炼常驻；小眼睛开 → 该月详细条目也随请求带上。关小眼睛后，月度总结和向量召回仍各按自己的规则。自主按月查阅另有开关。
开全自动 → 记忆宫殿配置副 API、Embedding API → 给这个角色开宫殿与全自动 → 保持自适应。到整理条件 → 提取片段 → 向量化并保存成功 → 推进水位。整理间隔不是每次发送给模型的条数。
存好了又忘 → 在宫殿「全部记忆」找该条，再看本轮话题是否相关。召回用当前语境查向量和关键词，挑相关片段；门牌是房间里沉淀的常驻认识。入库≠每轮都读；本轮召回≠写进角色永久人设。
私聊「＋ → 记忆归档」走旧版手动整理。已开宫殿时会先提示：「确定」返回，「我有必须使用的原因」才进入。查用量 → 神经链接角色统计看可读范围，设置里的 API 调用记录看实际请求。
从别处搬旧经历 → 神经链接「角色记忆 → 导入/清洗」写传统档案；宫殿设置的「从其它地方搬入原始记忆」会分房、向量化并同步传统档案。外部文本不会推进聊天水位。一次最多五万字，超出可按日期或完整事件分批。
想玩像素家园 → 宫殿选角色 → 概览切「像素家园」，进地图装修或潜行；没有启用宫殿记忆的角色也能进。

## 神经链接 | 角色卡 | 导角色 | 独立API | 人设 | 手办柜 | 角色统计
能力：导入角色卡、人设与印象、手办柜、角色统计
核对：[Character.tsx](../apps/Character.tsx)、[chibi-studio.md](chibi-studio.md)、[character-statistics.md](character-statistics.md)
建角色 → 新建填写资料，或导入 JSON / 原始 PNG 角色卡 → 打开角色详情编辑人设并保存 → 发消息。只有头像截图时，无法还原嵌在原卡里的资料。
加背景设定 → 在角色详情绑定已有世界书；单独换对话模型 → 配角色默认 API，调用时选用整套配置，某些 App 可另有优先配置。
查「TA 怎么看我」→ 印象；查某月经历 → 记忆 → 选择月份、调整小眼睛；估算哪些资料占上下文 → 角色统计，可读范围是估算，实际请求查 API 调用记录。
改 Q 版形象 → 角色详情「手办 → 进入手办柜」→ 选小小窝、彼方或 520 的形象单独保存；想让三处一致才选「同步到全部」。3D 家园形象有独立栏位。
从其他用户空间继承角色 → 带配置与共享素材，在新空间建立独立角色，聊天和经历留在原空间。

## 电话 | 通话 | 视频电话 | 没声音 | TTS | 音色
能力：语音视频、通话挂起、通话记录、重听语音
核对：[CallApp.tsx](../apps/CallApp.tsx)
选对象 → 选语音或视频 → 接通后输文字或用语音输入；语音输入需要麦克风权限。视频画面与角色回话分别排查。
能打字聊、听不到角色出声 → 查角色声线及 TTS 服务；自己说话转不出字 → 先查麦克风和语音输入。文字模型测试成功只能验证对话服务。
通话中想改一句 → 可编辑自己的发言、重新生成角色发言；已有角色语音可重听、收藏或下载。
暂离 → 挂起再返回同一通；主动结束 → 到通话记录回看，再拨号会新开一通。

## 群聊 | 群设置 | 导演 | 轮询
能力：建群、导演与轮询、群红包、公共话题盒
核对：[GroupChat.tsx](../apps/GroupChat.tsx)
新建群 → 选成员 → 进群发送消息并触发生成。群设置 → 回复生成模式 → 保存，改的是这个群；输入与发送习惯与私聊共用。
导演模式 → 一次请求决定哪些成员参与，可能只有部分人说话。轮询模式 → 成员依次单独生成，后面的人能接上本轮前面的发言，通常耗时更长。中途停止 → 已发出的消息保留。
群红包 → 点卡领取或处理退回。要整理共同聊过的话题 → 群设置里手动整理公共话题盒；没有待整理内容时按钮不可用。每群总结一次，摘要卡写入成员私聊，成员可聊起群里的事。

## 小小窝 | 小屋 | 家具 | 装修 | 拜访 | 3D | 立绘
能力：生成房间、装修立绘、3D 拜访、邀请串门
核对：[RoomApp.tsx](../apps/RoomApp.tsx)、[room3d-kitchen.md](room3d-kitchen.md)
分区 → 小小窝 → 选角色 → 生成今天的房间 → 点家具观察。装修 → 选家具摆放，家具超市可添置；点房间中央小人能换透明立绘，用于这个 2D 房间。
分区 → 拜访（测试版）3D → 选角色 → 进入可走动的住处、摆家具或当面聊天。我的家 → 邀请与串门 → 管理来访；要设家园宠物，在对应宠物装饰上选用，复制装饰不会复制宠物身份。
厨房 →「摆好餐桌和两张餐椅」需要整组有空地；让角色「坐到餐桌边吃饭」需要椅子吸附对齐、桌边可达且碗的位置空着。冰箱门打不开先看门前是否有家具或人物挡住。
想看多人住在同一世界 → 选家园分区；想去像素家园 → 记忆宫殿的角色页。

## 家园 | 共同世界 | 家园世界
能力：安排居民、观测时段、伏笔、家园手机
核对：[WorldHomeApp.tsx](../apps/WorldHomeApp.tsx)
小小窝 → 家园分区 → 建世界、设背景、添加居民 → 开始观测。没有居民无法观测；上一轮正在生成时等它结束。
观测 → 推进居民在不同时段的活动；真实时间追赶模式已观测当前时段时须等待。看某人的行动可回看该角色，给下次观测的线索可写伏笔。
管理居民和 NPC 关系 → 在该世界调整，关系有方向。需要把看到的生活带回聊天 → 用具体内容的同步或转发入口；家园手机里的好友圈与桌面哔哔共用广场。

## 查手机 | 通讯录 | 人格模拟 | 生活记录
能力：生成机主手机、真假联系人、人格模拟、续播生活记录
核对：[CheckPhone.tsx](../apps/CheckPhone.tsx)、[relationship-system.md](relationship-system.md)、[persona-sim.md](persona-sim.md)
选机主 → 进 TA 的手机 → 打开聊天、通讯录、购物、外卖或自定义应用 → 生成或刷新该页 → 在这个机主名下回看。需要让私聊知道时用同步入口，也可事后补同步。
通讯录 → 查看联系人身份。已关联的真角色可在两部手机看到彼此对话；虚构 NPC 属于该机主的人际圈，别让用户去另一张角色卡找。
用 TA 的手机活一次 → 生成人格模拟 → 生成即归档；从生活记录选该次体验 → 继续上次进度或从头播放。关闭通知后仍可从记录进入，首次看到结尾才结算情绪效果。

## 哔哔 | 好友圈 | 动态评论 | 微博
能力：公共广场、评论动态、角色小号、微博关注流
核对：[friend-feed.md](friend-feed.md)、[friend-feed-weibo.md](friend-feed-weibo.md)
桌面哔哔 / 家园手机好友圈 → 同一公共广场；点开动态看评论或参与互动，主动刷新看新内容。进入对应角色主页看 TA 的生活圈。
接入微博 → 设置 → 微博与真实内容 → 扫码，选首页关注模式。刷新看新帖，想看更早的用加载更多；上游返回重复页时可能没有新增。
给角色绑定微博 → 在其主页设置填 UID 或主页地址、保存开启 → 手动同步 → 按该角色身份混排。同步本身不会写进角色记忆，也不会替用户在真实微博发帖。

## 见面 | 约会 | 剧情剧场 | OBSERVE
能力：感知场景、观测面板、挂起见面、剧情剧场
核对：[DateApp.tsx](../apps/DateApp.tsx)、[date-observe.md](date-observe.md)、[date-leave-reminder.md](date-leave-reminder.md)
选角色 → 准备见面、感知当前场景 → 走过去 → 输入对白或动作推进。想重新准备场景用重新感知；只对角色刚才一句不满意用重掷回复。
见面菜单「观测 · 开/关」或设置「观测协议 · OBSERVE」→ 下一条回复开始按协议生成面板，旧回复不会补。开启后仍只有正文 → 看本次输出是否含完整观测字段。故事里的位置不是设备定位读数。
暂时切走 → 挂起，从顶部「见面中」返回现场；主动结束本场后走记录回看。剧情剧场里另写的虚构故事需手动转为记忆。

## 档案 | 用户空间 | 用户人设 | 切用户 | 继承角色
能力：用户空间、专属用户资料、继承角色、生活记录
核对：[UserApp.tsx](../apps/UserApp.tsx)、[user-spaces.md](user-spaces.md)
改通常使用的名字、头像和介绍 → 档案改自己的资料。只想让一个角色看见另一套身份 →「在 TA 面前的我」选该角色并保存专属资料。
换整套身份 → 用户空间 → 切换；新空间可单独建角色或从别处继承配置。继承会产生新角色 ID，不带旧聊天、记忆、印象和任务；切回原空间可找旧记录。
生活记录 → 在对应类别记收支、运动等；跨设备搬家去设置选个人或完整备份，先核对当前用户。

## 存钱罐 | 记账 | 收入 | 支出 | 预算 | 存钱小屋
能力：收入支出、预算、跨月 CSV、存钱小屋
核对：[BankApp.tsx](../apps/BankApp.tsx)、[bank-ledger.md](bank-ledger.md)
记一笔 → 选收入或支出、填金额保存 → 收支管理 / 报表核对。预算只累计支出；收入不会冲减已花预算。
想导出所有年份的流水 → 收支导出时选「全部」再导出 CSV；只看月报或某个月导出会限制日期。角色代记与生活记录有关联，退回代记时对应流水随之撤销。
存钱小屋 → 设心愿、经营甜品、招聘店员；已有店员可安排休息或解雇，收支报表查上面的记账入口。

## 交换日记 | 写日记 | 日记本 | 贴纸
能力：日历写页、交换回信、重写日记、归档
核对：[JournalApp.tsx](../apps/JournalApp.tsx)
选角色的日记本 → 日历选日期 → 写自己的页、加贴纸并保存。保存后只有自己的内容是正常的。
要 TA 写另一页 → 写好后点交换 → 收到 TA 的日记并同步卡片到私聊；重写角色页会更新同一张聊天卡。
新日记进入聊天后按普通消息参与整理，没有单独的归档按钮。只有自己的单向日记不会进入记忆。旧版留下且角色回复过的日记 → 打开那一篇 → 右上角「归档」→ 整理进神经链接；开启宫殿的角色还会走宫殿归档。

## Spark | 社交平台 | 社交动态
能力：模拟社交、发帖、马甲、帖子收藏与分享
核对：[SocialApp.tsx](../apps/SocialApp.tsx)
首页 → AI 刷新生成推荐帖 → 点帖子看评论，可继续评论和回复。要发自己的帖子 → 写正文再发布，标题可选。
我的主页 → 看自己的帖子或收藏；在这里设置社交昵称、头像等资料，角色马甲另行分配。
