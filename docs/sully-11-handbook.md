# Sully-11 内部使用手册

每个二级标题是一页。竖线后是用户可能用的叫法，「能力」用于本机检索。三级标题是可独立查阅的功能区。11 号每轮都有全目录，先取最多两区正文，必要时再按编号补查最多两区。涉及用户自己的开关时，以本轮设置摘要为准。

### 发完消息让角色回复与闪电
发文字 → 先入聊天记录；要角色接话 → 点标题栏的闪电按钮。私聊输入框旁的「＋」打开功能面板；找不到聊天装扮、离开后消息或记忆归档时，在面板内左右滑动，或点底部圆点翻页。

### 自动回复与发送设置
发完想让 TA 自己回 → 私聊「＋ → 设置」→ 展开「输入与发送」→ 勾选「发完后自动生成回复」→ 点底部「保存设置」。发出消息后，草稿为空、输入框失焦且面板关闭 → 约两秒后生成；继续打字会推迟。「发送按钮代替生成按钮」开启后，有光标时发送，点空白失焦后同一键生成。这两项输入习惯对本机私聊及群聊共用。

### 点角色头像看名片、改角色设定与查看今日日程
私聊 → 点对方消息旁的头像，或滑到最新消息后松手、从消息区下方再向上拉一次 → 打开当前角色名片。

私聊「＋」→ 聊天装扮 → 角色名片 → 选择内置款或打开「角色名片制作器 ＋」自制 → 预览三个栏目 → 选择角色并应用。要切换聊天角色，点聊天顶栏的头像或姓名，再在「切换会话」里选角色。名片左侧有「当前」「设定」「日程」三个竖签。「当前」显示头像、姓名与备注。启用「日程与情绪」且开启情绪感知后，有心声或情绪才会各自出现。有说明的情绪可以点开阅读。心声优先显示最近一次情绪感知写下的内容，也可能显示当前日程时段的内心独白。
点左侧「设定」可编辑与「神经链接 → 这位角色 → 设定」共用的资料，包括核心指令、世界观、时间感知与时区、生活记录注入。修改保存到同一个角色，两个入口都能继续编辑。该页底部有「记忆链接」入口。
编辑长文本时，点「核心指令」或「世界观 / 设定补充」框右下角的「展开」。顶部「完成」收起编辑器，回到原位置。
想看角色正在做什么或之后有什么安排，点左侧「日程」，按角色当地时间查看全天日程。已开始的时段，点右侧 ▶「窥视这一刻」生成并播放小剧场，点 ↻「重看小剧场」播放已保存的片段。尚未开始的时段须等到点。关闭播放器回到日程，点「日程与情绪设置」能调整日程。私聊「＋」里的原入口也能用。

### 合并收藏
收藏一整段对话 → 长按消息 → 多选 → 选中原话 → 合并收藏。收藏保存当时的快照；之后编辑或删除原消息仍能读快照。想回原处 → 从收藏跳回聊天，须原消息仍在。
保存过的音频要再下载 → 私聊「＋」→「收藏」→「语音」→ 在对应条目点「下载音频」。读取收藏里的音频原件，App 打开系统分享面板，网页下载文件。

### 转账与聊天装扮
转账(金额、备注) → 发出转账卡 → 收款方领取或退回 → 聊天出现对应回执。要改背景、气泡或译文样式 → ＋ → 聊天装扮。

同一角色或全局范围内，每个装扮部件采用最后一次选择。比如先用「星轨 · 雾紫」，再单换气泡，顶栏、背景和心象继续用原来的样式。再应用带气泡的白框，就换回它配套的气泡。原件仍可在装扮库里重新选择。

聊天装扮 → 先选「白框」「气泡」等分类 → 点「装扮库」，直接浏览该分类的公开作品。打开聊天装扮预览 →「试用」→ 在当前所选角色的真实聊天里看效果。公开作品先勾选作者使用规范。屏幕中央「试用中…」里点「使用」只应用给该角色；点「返回」或系统返回，恢复原装扮并回到刚才的预览。

在「聊天装扮 → 白框 → 内置白框」选择「银晕」并确认角色 → 短句、连续消息和语音分别使用原稿的切角纸面。消息区按日期分隔，双方的收发时间显示在各自带白色辉光的圆形头像下方。「我的搭配 → 布局 → 时间位置」可单独更换时间的位置。角色正在用旧版银晕 → 更新后从内置白框重新应用一次，即可换上新版布局。

### 协同工作
一起处理文档 → ＋ → 协同工作 → 在工作窗口处理材料；选中本窗口消息转发后才进私聊。允许协同读取的聊天范围可单独调，空范围不会读取整段私聊。
协同工作里的「世界书制作」会生成糯米机 v1 世界书，安装前可预览分组和条目。

### 不回复排查
点过生成仍无回复 → 有 HTTP 报错查「接口排查」；裸标签、只剩心象查「掉格式」；想看这一轮带了哪些旧话查「记忆宫殿」。

### 表情包导入、改名与下载原图
私聊 → 笑脸 → 铅笔打开全屏「表情管理」。点「导入」可从手机相册或电脑多选图片，也可打开 ZIP。名称默认取文件名，压缩包按文件夹分组；在「导入到」选择「＋ 新建文件夹…」，填好名字点「创建并选用」，已选图片会保留。新组默认仅自己使用。在聊天面板点组内「＋」导入会预选当前组。旧图床链接仍可在「粘贴链接」按每行「名字--图片直链」添加；该入口同名覆盖。确认后回到表情库的目标分组，格式有误的行会留在输入框里供修改。
本地图片和 ZIP 导入会预览名字，同名同图跳过，同名不同图自动编号。可在预览修改名字。中途停止后，已经导入的图片保留，可以继续导入剩余项。默认压缩超过 96 KB 的静态 JPEG、PNG 和 BMP，最长边 768 像素，转为更小的 WebP 并保留透明背景。可取消「压缩较大的静态图片」以保留原文件。动图和糯米机导出的 ZIP 原样保存。
「角色分配」里点「选择角色」，可搜角色名或分组名，也可点「按分组筛选」后再选角色。

点「选择表情分组」打开竖向列表，输入组名可直接查找。组内可搜索表情、点单张改名，或点「选择」多选、全选当前结果、移动、导出、删除。单张本地图片导出库内保存的文件，多张导出 ZIP 并保留分组。图床表情即使有缓存也只导出 URL，单条链接也用 ZIP 保存；点「分享 / 保存文件」完成。表情分享 ZIP 不含角色分配。导入结果可直接点「为新导入的图片看图起名」。已有表情也能多选 → 看图起名 → 一键起名。所选图片在一次请求中一起交给设置里的主 API，主模型需要支持多图输入。名称通常为 2～5 个字，同名建议自动编号，可修改、留空或整批保存。模型漏答时可只重试剩余图片；服务商限制单次张数时，可返回重新少选几张。默认发送表情时，私聊里的角色读到「[用户 发送了表情包: 表情名称]」，群聊里读到「[表情包: 表情名称]」。本地和图床表情的格式相同。只有给这位角色开启私聊看图，才会额外提供图片或识图描述。

### 表情包分配给指定角色、专属分类与智能匹配
「角色分配」先选角色，再勾选允许 TA 使用的分组。组内管理可设为「仅自己使用」或「所有角色可用」。旧存档的空角色名单沿用全员可用。分配的表情名称进入角色的上下文，建议只分配常用组。仅自己使用的组仍可在私聊面板手动发送。
私聊「＋」→「设置」→「输入与发送」可开启「表情包智能匹配」，按名字匹配，点候选发送表情会保留已输入的文字。

### 角色能看到表情包的图吗，还是只知道名字
默认只读名字。想让指定角色看懂你在私聊发过的表情 →「角色分配」→「让 TA 看懂我发的表情图片」。开启独立识图 API 时会生成画面描述，识图失败时仍使用名称。其他情况下需要当前对话模型支持图片。只有实际发进私聊、在本轮历史范围内的表情会参与看图，会增加模型输入或识图用量；图库候选清单始终只包含分组和名称。

### 表情包破图、刷新排查与本机存储格式
「本机空间」显示当前用户表情库的本地图片文件、内置表情的图床缓存和其他图床缓存，占用按相同内容去重。仅外链条目不计原图字节。点分组可进入整理。「刷新排查全部表情」会复查破图，点「一键清理」再次确认；离线、限流和暂时超时可稍后重试。
本地图片复用项目的 IndexedDB 共享图片库，表情与聊天消息通过 blobref 引用原图。外链可读时原图缓存于当前用户空间。删除库内表情保留已发送的聊天图片。个人完整备份带本地图片文件、名字、分组与角色分配，图床表情只带链接；文字备份保留配置，媒体包给已有记录补图。

### 报错自检
状态栏「查看报错」→ 打开「报错自检」，先看哪项操作失败、建议查哪套配置；需要原文再展开「技术详情」（每条日志标明对话模型、记忆宫殿、主动消息 2.0、音乐代理、云备份、语音或 MCP 等具体模块来源及前后台/流式阶段）。查看后状态栏提醒消失，若后续还需回看或复制本次运行期间的错误日志，可到「设置」最底部展开「本次运行错误记录」；产生新的前台错误时会再次提醒。复制全部日志输出带版本信息的结构化诊断内容，剪贴板受限时可在文本框手动复制。

看到「缓冲区提取失败」→ 在同一张报错卡上看这批记忆使用的 API、请求模型和失败阶段。接口返回错误、读取回复中断、收到完整回复后解析失败会分别标明。有 HTTP 状态码时会一起显示，包括接口返回成功但内容无法解析的情况。

### API 调用记录
发完消息没有触发生成 → 先查输入设置。已经生成过 → 设置 → API 配置 → 底部「API 调用记录」→ 找对应 App、用途和发生顺序。先区分主回复、副 API、向量化、语音；语音和向量化有自己的接口。

### 状态码与额度
401/403 → 核对这次实际使用的凭据、模型权限；429 → 看服务商返回的限流或额度说明；上下文超限 → 核对输入原文范围和输出额度。单凭红窗不能判断欠费。

### 模型列表与白屏
拉不到模型 → 核对所选接口类型、服务方给的地址和模型；地址是否要 /v1 取决于服务。白屏且还没发请求 → 问是整个桌面还是单个页面，记录复现动作，不建议清浏览器数据。

### 角色独立 API
主对话正常但角色单独失败 → 看角色是否用了独立 API。App 独立配置、角色配置、全局配置按该功能的路由选整套凭据；一次测试成功只证明被测接口当时可用。

### 确认现象
先问「在哪个 App？本来该出现什么，实际显示了什么？」看用户自愿描述的一小段去隐私示例就够。

### 指令原样显示
应出表情、转账、语音或双语气泡，却显示方括号指令、标签正文或残缺 JSON → 疑似模型输出不符合该入口协议。核对功能和角色开关、标签闭合、回复是否在中间截断。不同 App 的指令不能互用。
例：私聊显示“[[SEND_EMOJI: 抱抱”且回复在这里结束 → 查截断与表情名称；有文字却没译文 → 先查所选角色双语开关和输出是否包含完整原文/译文；HTML 模式关 → 不应预期富卡渲染。

### 自定义角色的心象提示词
长按心象卡片或点卡片上的「···」，进入「心象设置」，先选提示词作用范围。「所有角色（共用）」会修改当前用户空间的共用提示词；想给这个角色单独写，就选「仅当前角色」。随时可以切回共用。原先写过角色提示词的会自动保留为角色专属。默认「追加」会把你写的内容接在糯米机的默认提示词后。选「替换默认提示词」后，这个角色只用你填写的心象提示词；留空就不发送心象提示词。「显示心象」开启时，模型返回的思考摘要仍会显示在卡片里。

### 只有心象
只有心象 → 看是否另有回复正文。明确的思考字段或思考标签走心象；思考不能补作正文。普通英文、括号动作、外语对白本身都不能证明掉格式。

### 请求与显示异常
一直转圈或 HTTP 报错 → 查请求。内容完整但字看不见/输入框按不到 → 查聊天装扮或对比度。仅凭一次现象不要断定是模型坏了；先用同一入口的一条短消息验证。

### 翻译与外挂字幕
想开双语或把译文放到气泡外 → 进目标角色私聊「＋ → 设置」→ 展开「翻译与语音」→ 开「消息翻译」。先选气泡显示语言和翻译目标语言；在「译文显示」选「外挂字幕」才会出现「字幕设置与预览」。调好字号或颜色，点字幕页右上角「保存」，回聊天设置点「保存设置」。想让两种文字都留在气泡内就选「同时展开」。

### 原文与长期记忆
「我明明聊过」→ 先区分聊天里还能翻到、这轮带了原文、已经整理成长期记忆三件事。私聊、通话、见面共享该角色允许的上下文；群聊另有公共记录，独立玩法按各自规则回传。

### 原文范围与断点
查原文 → 私聊「＋ → 设置 → 上下文与记忆 → 查看原文范围 / 设置用户断点」。手动 = 最近设定条数；自适应 = 成功整理的水位之后；用户断点再收窄范围。退出范围仍可在聊天里翻看。

### 月度总结与小眼睛
传统档案 → 神经链接 → 角色 → 记忆。月度精炼常驻；小眼睛开 → 该月详细条目也随请求带上。关小眼睛后，月度总结和向量召回仍各按自己的规则。自主按月查阅另有开关。

### 开启全自动记忆
开全自动 → 桌面「记忆宫殿」角色列表顶端点齿轮（未配向量时也可点「未配置 Embedding API」）。填副 API 后点「保存副 API 配置」，在 Embedding 一栏选向量模型并点该栏的「保存配置」。回角色列表，在 TA 的卡片上依次打开「记忆宫殿」「全自动记忆」，上下文保持自适应。

### 追平历史
开完弹出历史处理选择 → 想现在整理积压消息选「立即追平历史」；想按平时的节奏跑选「稍后按所选档位慢慢处理」。提取片段、向量化并保存成功才推进水位。整理间隔不是每次发送给模型的条数。

### 查看已存记忆
存好了又忘 → 在该角色宫殿概览点「查看全部记忆」找该条，再看本轮话题是否相关。召回用当前语境查向量和关键词，挑相关片段。门牌是房间里沉淀的常驻认识。

### 手动归档
私聊「＋ → 记忆归档」走旧版手动整理。已开宫殿时会先提示：「确定」返回，「我有必须使用的原因」才进入。查用量 → 神经链接角色统计看可读范围，设置里的 API 调用记录看实际请求。

### 导入旧经历
从别处搬旧经历 → 神经链接「角色记忆 → 导入/清洗」写传统档案；宫殿设置的「从其它地方搬入原始记忆」会分房、向量化并同步传统档案。外部文本不会推进聊天水位。一次最多五万字，超出可按日期或完整事件分批。

### 像素家园
想玩像素家园 → 宫殿选角色 → 概览切「像素家园」，进地图装修或潜行；没有启用宫殿记忆的角色也能进。

能力：原文范围与小眼睛、200/100 整理节奏、向量召回名额、回执与事件盒
核对：[四月向量记忆指南](../public/changelogs/2026-4.html)、[记忆系统概览](memory-system-overview.md)、[档位](../utils/memoryPalace/waterline.ts)、[提取与召回](../utils/memoryPalace/pipeline.ts)、[召回名额](../utils/memoryPalace/formatter.ts)、[事件盒](../utils/memoryPalace/eventBoxCompression.ts)、[界面](../apps/MemoryPalaceApp.tsx)

### 一件事会存在哪里
以「昨天一起去看海」为例。聊天里保存的是双方说过的原话；传统档案可以按日期记一段当天经历，再把一个月的日度记录精炼成月度总结；宫殿则能把「一起看海，约好下次再来」存成一条有日期、正文和标签的记忆，并给它配上供语义检索的向量。之后聊到海边，即使换了说法，系统也有机会找回这段经历。角色是否在回复里提到它，还取决于当下的对话。
原话和档案按角色保存在当前用户空间的本机数据库（IndexedDB）。宫殿把可读正文和对应向量一起保存，副 API 负责提取经历，Embedding API 负责把内容转为可比较的向量。即使使用本机存储，这两步也会用到配置的服务。可选的远程向量存储在宫殿全局齿轮的「远程向量存储（可选 / Supabase）」中配置。
已经开启 Supabase 的用户更新后照常打开 SullyOS 即可。首次后台核对时会弹出可关闭的小提醒；关掉提醒可以继续聊天。客户端复用保存的连接、已有云表和本地向量，自动补齐缺失记忆与扩展字段，无需登录 Supabase、执行 SQL 或重新做 Embedding。中断后从已确认的批次继续。多个用户空间在各自打开时处理自己的记忆。连接或权限有问题时，提醒里可以重试或直接查看设置。两端已有不同正文时保留云端原文，本机优先本地召回。
首次新建空白项目时，使用设置内「初始化 / 升级 SQL」建表；默认表为 1024 维。手动「同步本地向量到远程」按本地记录覆盖同一 ID，可查看成功、失败、尚未尝试和失败原因。
远程数量查不到会提示暂时无法查询。云端缺少当前角色的本地向量、尚在回填或确认失败时，该角色优先用本地向量召回。
同一角色的私聊、通话、见面共用允许读取的原文范围。群聊有自己的公共记录和公共话题盒；交换日记、书稿等按玩法把卡片或记录送回私聊。要查一段经历，先对上角色、来源和是否已回流。常规全自动整理成功后，同一批新记忆也会在神经链接留下按日期关联的档案；已有的旧档案可独立保留，开启宫殿不会瞬间把过去所有记录转换成向量。
想自己写一次传统档案 → 私聊「＋ → 记忆归档」→ 核对归档设置 →「开始归档」。已经开宫殿时会先出现旧版归档提示，点「我有必须使用的原因」才能继续。想把日度档案合成月度总结 → 神经链接 → 选 TA →「记忆」→ 打开目标月份 → 点「生成」，已有总结时按钮叫「重新精炼」。需要该月有日度记录。

### 小眼睛究竟管哪一层
神经链接 → 选 TA →「记忆」→ 选年份 → 点目标月份卡片右上角的小眼睛。蓝色是开启，支持详细记忆的对话会额外读取这个月的日度详细条目。已经进到月份里面也能切换：点「月度核心记忆」旁的「仅使用核心记忆」，会变为「详细回忆已开启」，再点一次可关。关掉小眼睛后，日度条目仍留在档案里，已生成的月度精炼总结仍是常驻概括，宫殿继续按需召回。
「允许自主查阅月度记忆」在同页的「记忆设置」里另行控制。它允许角色需要时按月查已经归档的详细条目，继续回复可能多一次 API 调用。想查某一句原话，走私聊「＋ → 设置 → 上下文与记忆 → 查看原文范围 / 设置用户断点」。短按希望保留的第一条可设用户断点。手动模式读设定的最近条数；自适应读本轮水位线之后的原文，断点还能继续收窄。退出模型的原文范围后，用户仍能在聊天记录中翻看。

### 什么时候写新记忆：200 / 100 怎么算
开全自动 → 宫殿角色列表顶端齿轮配置副 API 和 Embedding API，各自保存 → 回 TA 的角色卡，打开「记忆宫殿」和「全自动记忆」。卡片上会出现「聊天记忆整理节奏」。只开「记忆宫殿」时，普通私聊也能按话题找旧记忆，回复后条件满足也能提取新的向量片段。再开「全自动记忆」，系统会把新整理的片段同时记进神经链接的日度档案，并把聊天原文切为自适应，跟随整理进度。只关「全自动记忆」，原文切回手动范围，宫殿仍可工作。
档位的两个数依次是「留作近期原文的条数 / 较旧且尚未整理的消息攒到多少才启动整理」。线上为主（默认）200 / 100；综合 100 / 50；见面/剧情为主 50 / 20。自定义允许近期原文 20–500 条、启动整理的缓冲 10–200 条，填完点「保存」。这些是每个角色的设置；问「我现在是多少」时，以该角色本轮的整理节奏为准。
默认档举例：从零开始，有 299 条符合条件的消息时，最近 200 条留作原文，外面还有 99 条，常规自动整理尚未触发。到 300 条，外面正好有 100 条，触发时先整理最早 85 条；接下来的 15 条留下衔接，再加最近 200 条。成功后水位移到这一批实际处理的位置。在自适应模式、没有额外断点时，例子里此时还可读到 215 条原文。日常每批取当时缓冲的 85% 向上取整；积压较多时，一批可超过 85 条。
计数单位是进入这个角色时间线的有效消息条目，一来一回可以有多条，也不是按天或字符数算。提取、向量化失败会保留处理进度供重试。整理 85 条原话能形成几个记忆片段取决于内容。手动选区总结不移动自动水位；「一键存入」按用户确认的边界处理，可选择保留最近 10 条，不能用它的数量解释日常自动整理。
已经够数却很久没有新记忆 → 在宫殿设置展开「低频维护 · API 有频率限制时使用」，查看「手动分步维护（所有角色）」。默认关闭。若已开启，回复后的自动提取暂停，旧记忆仍可召回。在该角色的宫殿设置点「开始 / 继续维护」，按「下一步」依次提取、逐盒压缩、整理门牌。

### 什么时候读旧记忆：每次能带多少
普通私聊在准备本轮回复时，用当前对话中的话题、意思和关键词找相关旧事。前提是该角色已开宫殿、Embedding 配置可用、库里有可用记忆。已有记忆无需再等 100 或 200 条新聊天；没有匹配内容时，这轮也可能没有相关旧事。问到具体打分或内部提示词时，只讲这个使用原理、可调的名额和本轮回执，不推测公式或阈值。
普通对话的主召回默认最多 15 个名额。独立片段占一个；同一事件盒命中几条合为一个名额，可带出盒摘要和仍活跃的细节。有效的置顶便利贴另算。可用结果少于上限时就少带，所以界面显示的片段数、原文条数和召回名额各有各的含义。
想调数量 → 主召回的 15 个名额没有普通用户滑块。想在主路之外多找一些 → 宫殿角色列表顶端齿轮 →「Rerank 模型（可选 / 二次排序增强）」→「启用 Rerank 通道」并配置兼容服务 →「额外召回条数（TOP N）」→「保存 Rerank 配置」。这个全局通道默认关闭，开启后的额外名额默认 5，可设 1–20；去重后有多少可用结果才追加多少。调「聊天记忆整理节奏」改变存入时机，调「上下文最大条数」改变直读原文范围。
「召回之后存在哪？」→ 本轮取出已有记忆给回复作参考，本机按角色留下实际注入的记忆编号回执；同一件事被想起三次，库里仍是原来的记忆。私聊「＋ → 记忆链接」可按本轮回执排查带进了什么；本轮没有回执时不会拿上一轮顶替。之后聊天里发生的新事、补充或纠正，要等整理流程才会写入。

### 同一件事怎么成盒、什么时候封盒
整理新记忆时，如果「约好去海边」「出发那天下雨」「后来终于看到了海」被识别为同一条事件线，就会新建或加入事件盒。手动关联 → 记忆宫殿选 TA →「查看全部记忆」→ 点一条记忆 →「关联事件」旁点「+ 添加关联」→ 至少输入两个字找另一条 → 点该条旁的「绑入事件盒」。无关联的片段可以单独保存。一次召回同时想起两件事，本身不会自动把它们封成盒。
盒里待整合的活跃片段达到 4 条，会尝试用副 API 将这些细节与已有摘要整合成一段连贯回忆。新摘要成功向量化后，参与整合的原始片段转为归档，仍可在盒内回看。以后命中该盒，通常带整合回忆和新近尚未整合的细节。整合失败时保留原内容。
整合后，累计事件片段达到 12 条会封盒；后来的相关进展另开延续盒。想核对 → 记忆宫殿 → 选角色 →「查看事件盒」→ 展开盒子看整合回忆、近期片段、归档片段或「已封盒」。需要重做摘要可点「重新整合」。门牌另存从经历中沉淀出的长期认识，作为背景提供给角色。
四月原指南在「使用帮助 → 更新日志」中。它解释了为什么引入向量记忆；后来新增的整理档位、回执和界面操作以本页为准。

### canary 抢先体验
canary 类似测试版，只在 friedsully.com 上提供，和正式版共用同一份数据。通常情况下加入不会导致数据损坏，但仍然推荐勤备份。

退出 → 设置底部标签点「正式版」→ 确认。Worker 会一起换回正式版，这一次没换成的话，下次打开会自动再试。
canary 打不开 → 连续两次没启动成功会自动回到正式版，并提示一次。用浏览器打开 friedsully.com 的人，也可以访问 `https://friedsully.com/?channel=stable` 强制回到正式版；添加到主屏幕的 App 和浏览器的数据是分开的，这个网址对主屏幕 App 不起作用。canary 用户别同时在 github.io、Vercel 上开着正式版：两边会轮流把 Worker 拉向自己的版本。

### 云端生成：私聊、日程、人格模拟、梦境交给后台写
「主动消息 2.0 → 功能总览 → 云端生成」按功能列开关：「私聊」一个开关（关掉后所有角色的私聊回到本机生成；角色的 2.0 面板里还能单独关）；「日程」「人格模拟」「梦境」各有「云端生成」和缩进的「完成时通知」，功能关着时「完成时通知」置灰、原值保留。缺省三项都云端生成，人格模拟和梦境完成时通知、日程不通知。云端生成不是秒回，模型等待时间和 API 费用照常，变的只是在哪儿写：交出去之后切到后台、锁屏、杀后台都不中断。
生成交出去、后台确认收下之后，屏幕顶部（状态栏下方）弹出小条「云端生成 · 日程」（或人格模拟、梦境；几位角色同时在写显示 ×2，几个功能同时在跑就并列写出）。小条停 3 秒自己往上收起，往上滑可以提前收起；只收这一次，下一次交给云端还会弹。日程写好后变成「日程好了 · 进入」，一直留着，上滑收走；人格模拟、梦境写好后用原来的「… · 进入」胶囊。在小条收起前点它打开说明：这次在云端生成，可以暂时退出应用；这次会发通知且这台设备收得到时写「生成完毕会弹出消息通知」，否则写「生成完毕后，回到应用就能看到」。说明底部「本功能不再提醒」只关这一项的小条，生成照常走云端；日程的「日程好了 · 进入」也不再出现，人格模拟、梦境写好后的「进入」照常出现。想恢复 → 回到「功能总览 → 云端生成」，那一项下面点「恢复云端生成提醒」。不再提醒只记在这台设备上，不进备份。
日程写失败时不显示小条；人格模拟、梦境失败沿用各自原来的报错。

### 本机数据被清空、没有备份时用救援模式取回云端数据
只适合本机数据丢了又没有备份、但 2.0 的 Worker 还在的情况。能取回每个角色的名字、日记、云端保存的凭据和角色发过的消息；开着定时主动消息或挂着排程的角色，还能取回最后同步的提示词快照（含角色卡、世界书、月度总结和最近一段对话）。没开定时主动消息的角色，云端没有角色设定，导回后要自己补。完整聊天记录、本地上传的图片、记忆宫殿和其他 App 的数据取不回。必须在原来那台 Worker 上做，救完之前不要点一键部署的「清空旧数据再装」，也不要先恢复旧备份再重连 2.0。步骤：Cloudflare 面板 → 主动消息的 Worker → Settings → Variables and secrets → Add，类型选 Secret，名字填 `AMSG_RESCUE_TOKEN`，值填一串至少 16 个字符、只有自己知道的口令 → 浏览器打开 `https://你的Worker地址/rescue` → 输入口令，点「开始导出」，下载 JSON → 导出完立刻回 Cloudflare 删掉 `AMSG_RESCUE_TOKEN` → 回 App：设置 → 备份与恢复 →「从其他网址 / App 迁入独立用户」，选这份 JSON。点普通的「导入备份」也一样，救援文件一律新建一个用户，不覆盖现有数据。Notion、飞书、MCP 等工具凭据不会自动导入，从 JSON 里手动复制。开启时所有登记过的设备会收到通知，App 也会弹红色安全警告，自己开的属正常。导出内容含 API Key，只存在自己设备上。详见 [amsg2-rescue.md](amsg2-rescue.md)。

### 看到红色「救援模式安全警告」怎么办
说明这台 Worker 正开着、或近 7 天内开过救援模式。弹窗要读满 10 秒才能点「我已阅读并知晓」，返回键关不掉。是自己开的 → 救完数据删掉 `AMSG_RESCUE_TOKEN` 即可。不是自己开的 → 当作数据已泄露：到各 AI 服务商后台作废并重建 API Key，Notion、飞书、小红书 Cookie 等工具凭据同样作废重建；改 Cloudflare 密码并开两步验证；作废不认识的 Cloudflare API Token；到 Cloudflare 审计日志（Audit Logs）查是谁、什么时候改了 Worker；救援模式还开着就删掉 `AMSG_RESCUE_TOKEN`。确认后 7 天内「主动消息 2.0」设置顶部会常驻红色提示，点「查看详情」可重看；之后又有新的导出或再次开启会重新弹。
