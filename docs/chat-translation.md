# 聊天译文样式

入口：聊天设置 → 翻译与语音 → 消息翻译 → 译文显示。三项同级单选：「点击切换」「同时展开」「外挂字幕」，每行一个小单选控件与一句说明，不再先开展开开关才能选字幕。

- 默认「点击切换」，点「译」切换原文／译文；「同时展开」沿用气泡里的分隔线与排版。「外挂字幕」默认白字黑描边，贴着原文最后一个可见文字片段的下沿，可越出气泡并覆盖时间戳、装饰或下一条消息，不为每条译文额外撑高气泡。
- 外挂字幕使用随应用打包的粗圆体（基于 ChillRoundF Bold v3.200，转换为 WOFF2 并按上游保留字体名要求重命名）。保留全部字形，仅开启外挂字幕后加载，遵循现有静态资源缓存；不依赖外部字体 CDN。字体许可证和来源随发布位于 `public/licenses/subtitle-rounded*`，重建脚本为 `scripts/build-subtitle-font.py`。
- 样式是展示偏好，不改变双语生成、`%%BILINGUAL%%` 解析或语音条的字幕。仅普通双语文本启用；关闭消息翻译或切到其他显示模式立即撤下字幕。底层继续用原 `chat_translate_expanded_` 与 `chat_translate_style_` 组合保存，旧用户选择不变。
- `chat_translate_style_${charId}` 按角色记忆；缺少或无效值回退 `bubble`，另一个值为 `subtitle`。沿用用户空间的私有 localStorage 视图，整合／文字备份及独立用户迁入都保留选择。旧包缺少此字段时不覆盖当前选择。
- 字幕模式下「字幕设置与预览」打开独立全屏子页，顶部沿用 `--chrome-top`／`--safe-top`，零安全区不补固定高度。字号 12–28、文字／描边颜色与字体先在本页草稿中预览，点顶栏「保存」才按角色应用并返回聊天设置；「还原」将草稿恢复默认，也需要保存。未修改时直接返回，有改动时，返回键、全局返回与 Escape 都提供保存、不保存或继续编辑；关闭确认窗只回到编辑，不退出父层。保存失败保留草稿，字体导入期间禁用保存。聊天设置保持原面板展开位置。
- 预览复用真实字幕浮层。内置圆体／系统黑体／宋体／跟随应用，并可导入 TTF、OTF、WOFF、WOFF2（30 MB 内），或选择外观当前字体、预设字体与已导入文件；不会更改系统字体。导入成功的文件进入共用字体库，放弃字幕草稿只撤销本次样式选择，不删除库中的字体。
- `chat_translate_subtitle_${charId}` 只存设置与字体 ID；`fontLibrary.ts` 把已校验的字体存入 IndexedDB 的 `font_library_<SHA256>` 资产和名称索引，同文件去重。外观 App 后续导入也加入此列表；旧版已被替换且未存在预设里的字体无法找回。只有字幕启用时加载所选 FontFace，预览与聊天共享并在不用时释放，不为每条消息重复读字体。
- 单用户 `chatSubtitleByChar` 和多用户私有 localStorage 保存偏好。字体资产作为文字／完整备份的一部分保留实际文件（JSON 中是纯 base64，不是会被剥离的图片 URL）；导入还原文件和选择，独立用户迁入同步换角色 ID。媒体补图包不改变这些配置，旧备份缺项保留目的地已有设置。
- `ChatSubtitleLayer` 在消息滚动区内提供独立、零高度的浮层，字幕不在气泡 DOM 内，因而不受气泡的 `overflow`、`clip-path`、圆角或局部层叠限制。Shadow DOM 隔离社区 CSS 的宽泛文字选择器；字幕仍受聊天滚动视口裁切，不覆盖输入栏或弹窗，也不接收点击／触摸。
- 位置取自原文 DOM Range 的末行片段，避开引用块和气泡底部留白。统一批量测量；随内容高度、窗口宽度、字体、主题和有限过渡重新定位。滚动时由同一滚动容器自然带动，无需逐条监听滚动；关闭外挂样式时不建立观察器。

验证：`scripts/test-chat-translation.mjs` 使用真实 `MessageItem` 和样式选择组件，覆盖默认、裁切、无框、深色气泡，引用、多行、Markdown、短原文长译文，320px／390px，内容增高、滚动、末条可达、触摸穿透、角色切换和重载持久化；另验证字幕草稿隔离、还原、保存／放弃／继续编辑、全局返回与 Escape、保存失败后的草稿保留、字体复用及模拟的顶部／底部安全区。测试入口为独立的 `test/fixtures/chat-translation.html`，不操作用户聊天数据；模拟安全区不等同于 iOS 真机验收。

## 公开白框兼容验收（2026-11-14）

`scripts/test-chat-translation-library.mjs` 在隔离 Edge 中通过正式美化库的搜索、详情、领取流程装载原件，使用正式 `ChatHeaderShell`、`MessageItem`、`ChatInputArea` 和 `BlobRefStyle` 渲染虚构聊天。作品只保存在测试页面状态，不写入日常角色配置，不修改或提交作者 CSS。

通过的六款：仿QQ 磨砂 iOS适配by秩（S-719F61E348EE）、仿微信 iOS适配by秩（S-99FB665850AC）、简讯iMessage 黑白 iOS适配by秩（S-36C07C186D47）、纸胶带（S-919767B5AE18）、Cyberpunk（S-F46892363B7E）、巨无霸简约（日夜）（S-E7480EF4BAF9）。每款检查 390px／320px × 系统浅色／深色，共 24 组；覆盖末行锚点、字体和颜色隔离、滚动、样式开关、新增长译文贴底、输入和长按。截图和结果在忽略的 `output/chat-translation-library/`。这是 Chromium 的手机宽度验收，不等同于 iOS 真机测试。
