## 镜子互动（2026-09-20）

落地镜、椭圆梳妆镜、精装梳妆台小物中的镜子、猫耳台式镜和猫耳梳妆台使用 `mirror.js` 的显式镜面注册，点家具显示「臭美」。同一房间 ID 有已摆放的猫耳/样板房双门衣柜时，再显示「穿搭」；收纳衣柜、换房或搬到其他房间会重新检查条件，不按名称或储物柜分类猜测。组合房间仍按家具所属房间 ID 区分衣柜条件。

镜前站位跟随家具旋转，桌镜计入承托柜深度，逐候选检查整个头部、身体与墙/家具空间；不能站在镜子背面或地板外，空间不足显示原因。样板房的落地镜可以直接使用；右侧梳妆镜当前朝向外侧，镜前空间不足时需重新布置。臭美从可用镜前站位直接开始；搭配穿搭按下述路线往返。暂没有实时镜面反射。

臭美沿用 12 秒活动生命周期，表现为歪头、抬手整理与轻微摆姿。搭配穿搭由 `mirrorJourney.js` 编排两轮「衣柜挑选 → 镜前整理衣摆、转身比划」，从角色当前站位出发，复用现有寻路与行走动作，按实际路程结束，不再固定 12 秒。无通路时直接瞬移到目标的安全站位，返回镜前受阻也同样处理；衣柜站位按旋转和头部/身体碰撞检查，完全没有安全落脚点时显示空间不足。`mirrorMotion.js` 控制原版刚性手球，新素体通过 `blankMotion.ts` 旋转骨骼；不拉伸四肢、不重建模型、不修改或保存服装。镜子互动仅保留「臭美」「穿搭」，不提供「休息一下」按钮；切动作、布置、收纳相关家具、换房会结束，减弱动态效果下臭美显示静态姿势，穿搭直接完成并停在镜前。家具架标记组合条件，衣柜本身不额外出现镜子动作。

`room3dMirror.test.ts` 覆盖有/无/收纳/跨房衣柜、镜前四向朝向、拥挤禁用、承托依赖与纯动作数据；`room3dMirrorJourney.test.ts` 检查两轮往返、绕障路线、无路瞬移和最终停回镜前；骨骼测试检查两种动作的几何不变和有限坐标。

输入：`Meshy_AI_assets_20260916_090743.zip` 的十份 GLB。清理图片、UV、顶点色后的几何制作源为 `art/jellyfish-home/sources/bedroom-*-geometry.glb`，生成器为 `pnpm node art/jellyfish-home/bedroom-assets.mjs`。材料人工选择奶油、浅紫、粉色、浅蓝和现有茶几 `woodLight`。不采样来源图像。

## 家具

拆成 25 件：梳妆台与圆凳、刷子盒、香水瓶、梳妆杯、双人床尾凳、落地灯、四款玩偶、衣柜、上下铺、高架书桌床与椅子/文具、单人床、双人床、床头柜与灯/闹钟、斗柜与台式镜/首饰盒/香氛瓶。衣柜前门破面重建；镜面使用平整浅蓝纯色表面，不增加实时镜面渲染。

家具架提供「卧室」集合和「玩偶」交互分类。所有新件指定实际存在的 `paintMaterials`，兼容预设色、自选主体色、原色、撤销重做和存档。四张床分别校准空间，双人床有两处躺位，上下铺有上下两个位置，高架床保留栏杆、梯子以及书桌下的空腔碰撞。梳妆台/高架床提供椅子吸附位置；梳妆台、斗柜、床头柜和书桌提供独立小物承托。

## 躺下

目录 `beds: [{id,label,position,rotation}]` 使用家具局部坐标，+Y 向上，rotation 绕 +Y。position 是躺姿根部对应的床面位置；睡眠根部额外升起 0.34，为头后侧的厚度留空间。`roomBeds` 和 `seatTransform` 复用放置、旋转、房间坐标转换；临时选择标记 `bed:true`，不会写进家具或角色存档。

「小人 → 躺下休息」选择具体床位，姿势为 `lying`，闭眼、轻微呼吸，**不显示脚球**。起身、切房、收纳床会释放位置。躺着时只提供休息/起身，选坐位或其它家具互动会转换姿势。上铺目前直接就位，无爬梯动画；尚无多人占位管理。

## 抱玩偶（用户明确要求）

玩偶是特别的可交互家具，目录 `holdable:true`，进入「玩偶」分类；大小要有“怀里满满一只”的感觉，不能变成手心小摆件，也不能遮住整张脸。鲨鱼、水母、海龟和抱枕玩偶都支持抱起。`plushPose` 按整个轮廓等比例缩放，抱起宽度约 0.6–0.78，最高到角色胸口附近；双手坐标按玩偶宽度与厚度计算，不伸长手臂、不压扁玩偶。

「小人 → 抱抱玩偶」可以站着抱，也可以保留普通坐位抱；站姿只显示手球，坐姿才有脚球。原实例暂时隐藏，抱着的呈现复用同一几何和该实例颜色；原位置、朝向、承托和物品数量不改。放回恢复原件，切换动作/房间、开始布置、收纳该玩偶或刷新时结束抱持。持有状态不进存档，避免重载复制出第二件。现在是面板手动抱起，没有走过去弯腰拾取的动画。
