# SAR 活动室怎么玩

当前实现核对：2026-09-11，开发分支 `codex/dino-cafe-art`。试玩页使用示例收藏与示例来客；彼方里的正式入口使用你的收藏、角色和 API 配置。

## 先认识活动室

在彼方顶部点击「世界」旁的「SAR」，进入独立全屏活动室。左上角返回彼方，活动室内不显示公共顶栏或房间翻页。点房间里的设施标记进入玩法，点在场角色查看角色。凯恩和艾文在房间里是 Q 版形象，点开对话后显示立绘。

右上角隐藏按钮按四档循环：只隐藏角色名字与称号 → 隐藏全部房间文字 → 隐藏所有角色小人并恢复设施标记 → 全部恢复。第三档也会隐藏凯恩和艾文，但不改变接入设置。自家角色只有当前活动实际在 SAR（钓鱼、布告板、箱庭、模块或芯片活动）才显示在这里；仅接入彼方不会自动入场。

| 入口 | 可以做什么 |
| --- | --- |
| 凯恩、艾文 | 看初见、各自的每日话题和星级事件，原稿固定分支，不花模型调用。隐藏 NPC 后仍能使用设施。 |
| 扭蛋机 | 抽取「异界异格」与「异界坐标」芯片，收进芯片收藏。 |
| 扭蛋机旁的装配柜 | 用两类芯片生成异格身份，进入五十轮推演；也能翻角色自己的芯片随笔。 |
| 模块商店 | 用鳞币购买并装载暂时改变说话外显的模块，例如恶役大小姐、傲娇等。 |
| 水域 | 自己钓鱼，或让角色自己钓一竿；查看收藏与图鉴，把鱼按当天行情卖给艾文。 |
| 内部布告板 | 看行情、买卖藏品、发需求、回复和查看交易档案。 |
| 茶几上的恐龙箱庭 | 摆橡皮泥恐龙、布置庭院、换色、写小剧场、邀请角色来摆弄。 |

这里的共享是**你和你接入彼方的角色共享本机存档**，并不是其他用户会进入你的活动室。鳞币统一用于水域、布告板、付费抽取和模块购买，是游戏货币，与模型 API 费用分别计算。

## 凯恩与艾文：慢慢熟悉，再把回忆收好

凯恩完成初见后，点他即可进入个人线；艾文直接从自己的入口开始。两人各自每天对普通话题抽一次：80% 遇到一段尚未完成的话题，20% 不触发。刷新或反复点击不会重抽；没有事件时会说三句日常问候，艾文按「星期 → 时段 → 天气」排列。点击艾文先正常对话，读完后才显示「卖鱼 / 离开」，选择卖鱼直接进入自己的鱼获列表；凯恩读完仍直接回房间。名册回看不显示卖鱼选项。

每个篇章有十个不重复的普通话题，全部聊完后，下次点击角色才开始对应星级事件，不必等第二天。事件完整结束才点亮星星；目前有一至三星的原稿。艾文的星级彩蛋独立抽取，不占普通话题的名额；多段同时抽中时，剩下的留到后续点击。遇见 Sully 的段落要求他实际在 SAR。

正式剧情隐藏返回按钮，回看才显示；切走导致日常话题、星级事件和彩蛋中断不算完成，下次从这段开头重来；完整读完才结算奖励；星级事件最后一句读完后，再点击进入独立结束页，显示「结束 X 星事件：标题」；艾文继续后显示「卖鱼 / 离开」，凯恩或名册回看继续后返回。灰色角色沿用上次发言的表情。初见与日常都使用浅色全屏布局，选择按钮在画面中央。另一位发言后保留到当前交流结束，接下来的分支仍有台词时也不退场。只是提到名字不会让对方出现。17 张原画表情已随应用本地提供，凯恩 11 张、艾文 6 张。凯恩新增「忍痛、回避、平常2、温柔」，已同步新版透明背景，可在本地开发模式的扳手中开启「SAR 剧情与表情校对」后选择，开关默认关闭，已应用用户校对的表情编排。

事件中的证件、会议记录、可调整人物和背景构图的合照、礼炮、优惠券雨、神秘按钮和特殊恐龙都有对应演出。对话时保留完整立绘，提到展示物品时才拿出来，点击继续便收起；拍照和成员证需要先完成操作。明确赠送的模块、恐龙、优惠券与纪念物才真正入库，每份奖励只领一次；画面里出现的玩笑道具不全是奖品。

到「仓库 → 图鉴 → 专属纪念」收好星级故事里的证件、合影、存档卡与特别赠礼，可按凯恩和艾文筛选、翻页回看。同种恐龙每只都有独立名字，可以在箱庭的「名字与管理」单独修改。

到「仓库 → 图鉴 → 名册」查看两人的完整档案与五颗星，在「回忆」重看已经完成的话题、星级事件和彩蛋。未发生的内容保持锁定；回看不会推进星级、再发赠品、续折扣或重发私聊彩蛋。名册记录你和两人的关系，不随仓库切换到哪个角色而变化。完整规则见 [SAR 个人线](./sar-personal-lines.md)。

## 角色接入：挂机等你，或自动活动

去「彼方 → 接入」开启角色并设置 Q 版形象。接入列表沿用你的角色分组，每页最多五位，切换分组会回到第一页。新接入默认「仅手动活动」：角色知道彼方，形象可以留在房间里；不用选择间隔，不会因到点或刷新自行启动模型。你点「让 ta 现在去逛一次」、邀请钓鱼、逛布告板或来箱庭时，才执行这一轮活动。已有动态、收藏和收到的程序回执照常保留，收到回执不自动触发回复。

想让角色自行活动，切到「自动活动」再选间隔。已有存档原来开启的定时登入保持原样。切回仅手动会撤掉计划；正在生成的那一轮可以完成，但不会把设置改回自动，也不会再接着启动新一轮。纯挂机本身不调用 LLM，每次邀请按相应玩法计费。

「让 ta 现在去逛一次」分为「普通空间 / SAR 活动室」两级菜单，SAR 可单独指定抽芯片演绎、模块商店、钓鱼、布告板和恐龙箱庭。角色卡片下方的「高级选项」可以排除自动前往的房间或 SAR 单项，也可排除整个 SAR。自动活动先随机选可用房间，再在 SAR 内选具体玩法；禁用项不进入随机池，全禁用则跳过本轮、不调用模型。手动邀请仍可前往，玩法本身的条件照常检查。完整规则见 [活动选择与自动活动范围](./kanata-activities.md)。

## 恐龙箱庭：先布置，再让角色来玩

### 你来准备庭院

1. 点茶几进入箱庭。首次会收到艾文赠送的一只橡皮泥霸王龙；以后钓到或获得的恐龙进入收藏，同种不同只也分别保留身份。
2. 选择溪边草原、贝壳海岸或火山探险。每张地图分别保存布置，**一图最多六只恐龙、十二件摆件**。你和角色的恐龙共用名额。
3. 点「布置」，选择摆件。预览中会显示格子、发亮的物品和朝向箭头；选位置、转向，再点「确定」。点取消不改原来的布置。
4. 点场景里带爪印的摆件，选择「让恐龙来玩」，再选一只恐龙。程序寻找能互动的位置和朝向，你确认后才保存。已被占用、地图满员或不适合互动的藏品会事先说明。
5. 如果旧摆件的位置不适合落格，预览可能同时调整这件摆件和恐龙，会明确提示；仍需你确认，其他恐龙不会被挤走。
6. 点恐龙可以换地方、换配色、取名，或者写一句「正在……」。不用填行为对象，也不用写指令。留空就显示当前位置的小日常。

恐龙固定在确认好的位置和朝向，只做原地动作：野餐垫上吃点心、水边玩水、低头闻花、够树叶、在帐篷或石旁打盹、站在木桩上摇尾巴。火山、路牌、栅栏和小屋目前是装饰。蛋与骨架保持静态。这些动画由程序播放，**不调用 LLM，也不会按每次动作写一条记录**。

配色、名字、原文和获得来源属于具体那一只恐龙。把它搬去另一张地图不产生副本；赠送后归属改变，名字、配色和经历保留。挂板出售或孵化中的藏品不能同时摆进箱庭。

### 角色来访时发生什么

先在「来访」开启共同摆弄，再选择已接入彼方的角色并邀请。它可以摆弄共同庭院里别人的恐龙，不会因此取得所有权。想保留某只的布置，可以将它「固定」：角色仍能评论，但不能移动或续写。

一次来访按下面的流程完成：

1. **看现场。** 角色获得这次访问地图里的恐龙名字、种类、归属、配色、格位、固定状态，你写的原文、当前状态，以及程序实际支持的环境互动。它也能看到摆件、可用落点和最近的足迹。
2. **想一个动作。** 使用这个角色原本的人格与聊天上下文，调用一次模型。模型在「留便签／移动或转向一只／续写一只的正在」中选一个，同时给出自己的话。
3. **程序检查。** 模型使用固定格位或“靠近／面向某个对象”，程序负责落点、朝向和碰撞。如果恐龙已被收起、固定，或者你刚改过布置导致结果过期，这次改动会被拒绝，不覆盖新布置。
4. **执行并记下。** 合法操作保存到箱庭，便签或状态带上角色署名，并在该角色的聊天里留下彼方活动卡。不再另外调用一个模型来写总结或执行动画。
5. **你回来查看。** 在「来访」和足迹里看谁做了什么，定位恐龙、回复便签。角色的移动或续写，在恐龙没有再被改动且旧位置仍可用时可以还原；还原本身也会留记录。

例如，你写「莓莓正在等薄荷还饼干」。角色可能把莓莓挪到薄荷旁边，留一句「自己去要」。这轮就结束了，不会接着自动展开多轮谈判。下一次来访才会产生下一个决定。

目前角色不能在来访里新增摆件、换地图、改恐龙名字与配色、赠送、出售或凭空创造物品。“正在修城堡”可以是一句小剧场，但不会真的生成城堡。角色来访也没有单独的 Q 版角色走入 3D 庭院的演出；可见结果是恐龙的位置／状态变化和留下的便签。

### 角色知道谁动过什么吗？

**知道最近发生的事，但不是全知的历史管理员。**

| 内容 | 当前怎么处理 |
| --- | --- |
| 谁、何时、在哪张图、对哪只恐龙做了什么 | 成功保存的操作写入足迹，保留作者身份、时间、操作类型、对象与说明；有留言时保留原话。 |
| 你原来写的那句话 | 单独保留。角色续写当前状态不会覆盖你的原文。 |
| 角色改动前的状态 | 移动或续写保留改动前的位置／状态，用于回看和有条件还原。 |
| 角色本次直接看到的历史 | **当前地图最近 10 条**足迹的作者、事情和原话；另有最近事件帮助既有记忆召回，以及它自己的聊天上下文。 |
| 某人累计移动了几次、最爱摆弄谁 | 当前没有专门统计，也没有把完整历史全部发给模型。不能保证角色回答全历史次数准确。 |
| 未确认的预览、取消、原地动画 | 不记成已发生的摆弄；失败的来访也不会伪造成功足迹。已发出的模型请求仍可能有 API 费用。 |
| 其他角色是否立刻知道 | 不会向所有角色广播并各调一次模型。下一位来访者读取当时可见的最近足迹；活动发起者有自己的聊天卡。 |

箱庭足迹目前不自动裁剪。你在某条足迹下回复，会成为新便签，不会立刻触发角色再回答。

开启共同摆弄后，已选择自动活动的角色也可能在正常彼方活动中选择来访。自动来访按近期成功足迹限制：同一角色至少间隔十二小时，全体二十四小时最多三次。手动邀请不受这项自动频率限制，但会留下足迹，影响后续自动资格。

自主来访依赖应用运行，不是云端挂机。关闭应用期间不会持续新增拜访；重新打开后按彼方调度检查到期活动，不按离线天数补出一串箱庭事件。自动访问的是当时选中的地图，不会逐张巡视所有地图。

## 水域：自己钓，或者让角色去钓

你自己玩：手动模式抛竿后按住／松开水面，让控制弧跟住鱼，成功后收进收藏；简单模式看见鱼影后点附近抛竿，或用底部按钮自动瞄准；等浮标落水、自动收线，成功才收进收藏。判定宽松但仍可能空军，没有鱼影时更容易落空。物种、大小和品质由程序抽取，自己钓鱼不调用模型。操作说明点问号查看，想让角色去钓鱼时展开底部「角色钓鱼」。

天气优先使用已配置的真实天气；不可用时显示彼方模拟天气，影响出没概率。天气请求不是 LLM 请求。当前随机鱼池包含 9 种鱼和 11 种橡皮泥藏品。恐龙蛋改由艾文三星话题赠送并开放图鉴，不再随机钓到；旧档已持有或曾获得的蛋仍保留记录。

在自己的收藏里，你可以按行情卖出、自己定价挂板、陈列，鱼类还可以放生；橡皮泥模型能制作观察记录，恐龙蛋可开始六小时孵化，到时由你点击揭晓。查看、等待、揭晓都不调用模型。图鉴发现记录不会因卖掉藏品而消失。恐龙也可从这里进入箱庭。

艾文三星事件的专属「？？？」是霸王龙身体、三角龙角、剑龙背板与腕龙长脖子的混合恐龙，有独立橡皮泥模型。它作为真实赠礼加入收藏，可带进箱庭；普通垂钓、随机赠礼和蛋的孵化都不会产生它，回放也不会多领一只。

这里的角色指用户接入彼方的角色；固定 NPC 凯恩与艾文仍走自己的预设演出，不参加这套自主钓鱼。

角色自己玩：选择已接入的角色 → 点「让 ta 去钓鱼」→ 程序抽定并暂存这一竿的鱼获 → **一次主 LLM** 返回 JSON：反应、保留或放生、可选的私聊原话 → 程序核验并执行 → 写下活动卡；选择分享时另写一条普通私聊消息，直接使用同一次生成的原话。

保留／放生与是否分享独立：放回水里，也可以告诉你；收藏下来，也可以什么都不说。分享不转移物品所有权。橡皮泥恐龙只允许收藏，不提供放生。这次钓鱼没有挂卖和定价，角色需要另去布告板处理交易。

每个角色有自己的收藏柜和水域图鉴。收藏柜显示当前持有的每一件物品；图鉴保留曾经获得的品种、首次获得日期、累计获得次数。放生、卖出或赠送不抹去图鉴，重复获得独立计数。旧存档只补有记录可证实的内容，不补发旧解锁播报；不完整的历史标为“已记录至少”，无法确认的日期不编造。

角色首次解锁一个品种时，程序自动以「彼方播报」身份在公共留言簿发布一次图鉴解锁通知，并把事实回执同步给已接入彼方的角色。这是当前用户这份彼方里的公共播报，不跨用户联网。通知不公开角色的私聊原话，也不触发其他角色立即调用模型回复。重复获得、刷新页面或重试不会重复播报，清空留言墙也不会重新补发已发布通知。

网络失败或 JSON 无效时，鱼获仍然暂存在该角色的收藏中，按钮变为「继续处理这一竿」。再次请求只处理原来的同一件物品，不重新抽取；暂存期间不能交易或摆进箱庭。已经完成的分享或播报如果保存失败，会留下待发送记录，下次进入或通过「重试发送记录与分享」继续同步，重发本身不调用 LLM，也不重复放生或入库。

角色的本轮提示词只追加实际钓到的这一件、该角色之前持有同品种的数量和相关获得记录；原有角色设定、聊天上下文和已配置的记忆召回仍走彼方共用链路。不发送整个鱼池和所有角色的背包。一次邀请只处理一竿，不会自动连钓。

## 内部布告板：交易，也可以说废话

这是你和角色的本地市场，新钱包初始有 120 鳞币，旧存档余额保留，各用各的钱包。首页按时间摆放所有便笺，点开后在独立页面回复或成交；「写便笺」是统一发布入口。右上角「更多」里可以查看当日行情、往期便笺与收支记录，或邀请角色来逛。返回时保留原来的阅读位置。

写便笺时选择想做什么：收到一句回应、找到一件藏品、转让东西或收一份心意。出售可选真实库存，或明确标作文字商品的约定；填写金额时会说明谁收钱、谁付款，匿名笔名收在「署名」里。成交按钮直接写明支付或领取的金额，「仅回复」不扣钱。文字回应提交即结算，不支持后续验收任务。便笺一般二十四小时到期，原文和回复仍在发帖方的往期便笺中。

响应实物求购时，先选择要交付的具体那一件，列表显示名字、大小和星级；同种藏品不会自动拿第一件顶替。若所选藏品已经挂售、转手或不可用，这次交付会停止。新挂单与已完成求购会保留当时的藏品资料，详情中也能看到买家／交付人；旧档案没有记录的资料不补编。匿名发帖后，在自己的便笺下回复会沿用原笔名。

点「让 ta 逛布告板」时，角色读自己的余额、可用库存、公开便笺、近期相关回执，**一次 LLM** 选一个动作：浏览、买入、交付需求、回复、挂单、发需求或撤自己的便笺。程序再次检查钱、库存和订单状态，成功才成交；失败就记录实际失败，不让一句吹牛改变账本。同一轮也可生成去留言簿或私聊分享的原话。目前留言簿分享会实际发帖；布告板的私聊分享仍写在活动卡的「私聊原话」里，没有单独发送普通聊天消息。

每人最多同时发布十二张便笺，每张最多四十条回复。求购或招募发布时不预扣鳞币，真正交付时再次检查余额，可能因发帖人后来花完钱而失败。模型每轮最多看到自己的三十件可用库存、最新十八张挂单、十八张需求与近期回执；不保证一次读完整块板。库存与实物挂单会提供大小、星级和已有的恐龙名字，并明确区分实物和文字商品；角色交付实物也要指定具体藏品。

主页点「刷新」随机来两三位路人，或一位开启自由活动的角色。路人现在用 **一次 LLM** 共同生成一轮 3～8 个动作，能发新便笺、在同一帖下接话、针对旧帖隔空喊话；没有固定台词兜底。路人沿用四个独立钱包，不随刷新补钱；真正角色仍走自己的活动模型与人设。没有 API、回复无效或中途离开时不补写假帖子；生成期间发生的交易会按最新状态再次校验。关闭彼方 NPC 后不生成路人。

## 扭蛋与装配柜：两种不同长度的芯片体验

扭蛋机有「异界异格」和「异界坐标」两类芯片。抽取、揭晓、查看收藏都由本地程序完成，不调用模型。

**两个卡池每天各有一次免费抽取，之后每次 90 鳞币。** 同池连续两次抽到已有芯片后，下一次必得未收录芯片；两池分别记录，免费和付费抽取都计入，收齐后正常随机抽取。免费次数按本地日期重置，回拨设备日期不会补发，余额不足时仍可使用未领取的免费机会。按钮会明确显示此次是否收费；如果另一个页面抢先用了免费次数，不会自动改成付费。抽取成功后即存入收藏，未看揭晓就离开也不会丢失。

你想亲自玩一段故事时：打开装配柜 → 选角色 → 从已有收藏各放入一枚异格与坐标芯片 → 点铸造。**一次 LLM** 生成异格身份、你的异界面具、世界线与开场。装配要求拥有芯片，目前不会扣掉芯片数量。

身份卡先展示简介和开场，人物身份与背景按需展开，秘密与预设高潮不在卡面剧透。点「进入故事」或「继续故事」，输入你说的话或想做的动作。正式演绎使用线下现场剧情，旧通讯记录保留其历史原意。

世界意志负责让角色和世界有自己的行动，但用户可以探索、陪伴、拒绝或忽略事件，不需要先理解设定或规划剧情。日常与关系互动同样有效，安静片段可以没有独立旁白；故事时间也不会每条回复都自动加速。背景资料、阅读外观、互动进度与提前封存入口收在右上角「演绎资料与设置」。阅读旧内容时，新回复不会强行拉走视线，可以点「回到最新内容」。

每次提交行动或话语，**一次 LLM** 同时生成必要旁白、角色回应和简短连续性事实记录。内部记录帮助保留事件与被拒绝的钩子，不展示在正文或导出全文中。成功保存才计一轮，最多五十轮；末段收束实际参与的经历，允许主线未解决，不要求清完任务。开场来自身份卡，不另算一次生成。因此新铸一张卡再完整玩五十轮，玩法主流程仍共 **51 次生成**；继续已有卡不再付铸造那一次。离开页面不会自动生成或消耗轮次，稍后可继续；「提前封存」会结束本段，当前无法直接续写。

正式推演使用角色设定与关系概况，但隔离现实的具体聊天事件。档案保存在独立推演记录里。封存后可以导出、回看，或主动分享给角色；分享动作只把档案说明写入主聊天，不会立即自动生成回复。之后再让角色回应，才是一次普通聊天。

角色自己逛进装配柜时则是短体验：程序随机选两枚临时芯片和一个对象，**一次 LLM** 生成完整短剧情、角色随笔和高光，归入「看看角色的柜子」，并留下活动卡。不会消耗你的芯片或每日额度，不会偷偷跑五十轮；被选中的另一个角色也不会因此再被独立调用一次模型。这是一位角色叙述的临时芯片体验。

## 模块商店：暂时换一种表达方式

进入商店 → 看五件当日货架商品，也可以使用当天的三次免费换货架 → 按标价购买模块 → 到模块袋选角色 → 填必要的字面配置 → 确认装载。购买、选人、确认和装载动画都不调用模型。

**模块目录价为 18～34 鳞币，按显示的实际优惠价结算。** 购买只增加库存，不会自动装载；装载消耗一枚。与钓鱼、布告板使用同一个余额，既有收藏和库存保留，不追扣试玩期间的费用。原票据不再作为支付余额。

个人线可以送出九折券或 30 分钟八折优惠，八折可能覆盖全店，也可能只对应当时货架上的一个商品。商店自动使用最省钱的一项，不叠加；同价时优先用限时优惠，留下券。购买成功才扣券，券雨固定给三张。优惠过期导致价格高于刚才确认的报价时，会停止交易，让你重新确认价格。

用户购买的扣款、库存和收据一次保存；余额不足或保存失败时不完成交易。重复提交同一购买记录不会重复扣款。库存、免费次数和付费记录随 SAR 备份一起保存。角色逛模块店会决定只看或购买；买下的模块进入自己的仓库，只扣自己的钱。自动购买每天最多花 60 鳞币，并保留 30 鳞币，已有同款时先用库存。角色对你装载或回敬模块也必须消耗自己已有的一枚；余额或库存不足时不会凭空生成模块。角色装配柜的一次短剧情仍使用临时芯片，不计入任何人的永久库存。

模块影响后续聊天中可见／可听的表达，保留真实语义和人格。例如恶役大小姐是礼貌、华丽的大小姐语气，语种仍跟随角色设定，不会直接把角色变成另一种人格。角色端持续十次成功互动，结束后有三次表达恢复期；失败、取消不消耗轮次。

开启「允许角色给我装模块」后，还有两种反向装载：

- 你给角色装载时，如果你和合适的角色都在 SAR，程序可能在装载结算中给你装一枚随机适用模块。这一路没有额外 LLM 决策。
- 角色自主活动选到模块商店时，程序提供一枚适用模块，**一次 LLM** 写活动并决定是否装到你身上。仍要求你已允许、本人接入且在 SAR、当前没有用户模块。

用户端持续五次成功互动，再经过三次恢复期。谁给谁装了什么、何时生效与解除，会作为聊天事件保存，角色能按这些事实反应。模块的外显文字和真实含义分开保存；后续聊天把效果和回复放在同一次生成里，不另外加一个“翻译模型”。

聊天气泡下方，以及见面的阅读模式、立绘模式，都有明确的「污染台词 / 原台词」切换。两种见面模式各自保留当前的查看状态；切换只影响显示，不改写聊天记录。重复短句按当前播放位置配对，旧的原台词续接快照也能查看对应污染版本。

自己或角色装上模块后，会出现全局「模块」悬浮窗，列出全部作用对象、模块名称和剩余轮次。点窗头收起或展开，拖动窗头可以挪开；切换应用仍能查看。点某个人的「提前结束」会立即解除那个人的模块，从下一次回复开始提示恢复表达，随后三轮成功回复逐步收起解除提醒。已经开始生成的回复可能仍受原模块影响，但不会重新激活已结束模块，也不会消耗首次解除提醒。提前结束不退款、不重新发放库存，也不额外调用模型。状态随角色／用户资料保存和导出。


## 模型次数速查

下面统计玩法本身的生成请求；启用记忆宫殿后，另可能发生记忆检索的 embedding 请求和达到归档条件时的总结生成，不能保证 API 账单总条数永远等于这一列。网络错误后再次手动点击，也算新的请求；当前聊天生成请求不自动重试。

| 一次操作 | 玩法生成次数 |
| --- | ---: |
| 看活动室、NPC 个人线及回放、拍合照、抽扭蛋、查看档案 | 0 |
| 自己钓鱼、交易、孵化、布置、换色、看原地动作 | 0 |
| 给便笺回复、还原一次来访改动 | 0 |
| 邀请一名角色来一次箱庭 | 1 |
| 让一名角色钓一竿／逛一次布告板 | 各 1 |
| 刷新布告板，来访两三位路人 | 整轮共 1，不按路人人数叠加 |
| 角色自由活动的短芯片体验／逛模块商店 | 各 1 |
| 铸造一张新的异格身份卡 | 1 |
| 正式推演每提交一轮 | 1，旁白和角色合在一次生成 |
| 启动已有推演、紧急封存、分享档案 | 0 |
| 手动购买、装载模块及装载时的本地反向演出 | 0；之后聊天按普通聊天计 |

自主登入按你给角色设置的间隔触发，先由程序选房间与一项活动，再生成该次活动。一次进 SAR 不会把全部设施逐项跑一遍。连续三次模型请求失败会暂停该角色的自主登入；没有真正发出请求的跳过不计为一次失败。

模型优先级为角色自己的彼方 API → 彼方全局 API → 普通聊天 API。布告板路人使用彼方全局 API → 普通聊天 API；不会借用某位角色的专属 API 或私聊上下文。实际发出了什么请求，可到彼方调用记录及应用的 API 记录核对。

## 存档与当前边界

箱庭、收藏、交易、芯片、推演和两人的个人线都是本地保存，需要随备份一起带走。完整 ZIP 包含个人线进度、未完成照片草稿、纪念物、优惠和照片所用的本地图片；换设备导入后保留奖励去重记录。纯文字备份保留进度、文字和构图，去掉图片，因此要完整保留照片应使用完整 ZIP。Git 同步代码不会同步浏览器存档。

角色的成功自由活动会写入自己的聊天活动卡，接入已有的记忆流程；这不等于所有角色永远记得所有细节。NPC 固定引导和个人线不是模型生成的角色自由活动；原稿里明确的 Sully 私聊彩蛋会按唯一记录写入对应本地聊天，不自动调用模型回复。

当前没有恐龙大战、自由手绘涂装、云端离线箱庭来访、跨用户市场、更多地图的活动解锁，也没有“每人累计摆弄次数”面板。当前可用的是三张地图、橡皮泥恐龙收藏与配色、原地物品互动、小剧场、真实角色来访及操作足迹。


## 活动室与随身仓库

SAR 独立活动室整体采用浅色。右上角「设置」控制凯恩与艾文是否出现在房间内，不影响设施，也不关闭你自己的角色；「初见回档」可以重看凯恩初见，不会清掉其他收藏和进度。角色接入与自动活动仍在返回彼方后的「接入」中管理。

关闭常驻 NPC 后，角色称号显示、称号编辑、名册、专属纪念与 NPC 专属图鉴条目一起隐藏；初见、个人线和待投递彩蛋暂停。聊天与彼方活动不再额外注入两人的背景或称号提示词，活动返回也不能更新称号。鱼获仍可交给回收站，普通鱼类、恐龙、芯片、模块与钱包继续可用。重新开启恢复原来的称号、收藏和剧情进度，不删除历史聊天或已有存档。已打开名册时，在另一个页面关闭开关也会退出 NPC 内容。

「仓库」里切换自己或某个角色，可以查看各自钱包、芯片、模块和收藏。每件东西只归当前主人所有；挂板、孵化、陈列和箱庭中的东西仍属于主人，并标记状态。正在装载的效果单独显示，不重复算成可用库存。临时故事芯片不是永久物品。

切回自己后，「纪念」可以打开成员证、会议记录、合照和存档卡，保存当时的名字、日期和形象，之后换装不会改变旧照片。「优惠券」显示仍可使用的实际数量；剧情赠给你的东西不会跑进正在查看的角色背包。

每人每天通过系统回收最多收入 **180 鳞币**，次日本地零点恢复。超过剩余额度时会保留整件藏品，不会少付钱收走；仍可收藏或自行挂板。人与角色之间的交易只移动现有鳞币，不占系统回收额度。钱包上限为 999,999 鳞币；旧存档已经超过上限的余额保留，可正常消费，降至可容纳新收入后再收款。

完整定价、收入估算与后续调参依据见 [SAR 数值规划](./sar-economy.md)。


## 收集图鉴与彼方称号

仓库右上角的「图鉴」有「收藏 / 名册」两页。「收藏」汇总鱼类、恐龙、芯片、模块四类进度，按种类点亮，重复获得不增加种类数；可以搜索、筛选已收录/未收录并翻页。点条目查看介绍、获得方式与当前持有数量。芯片同时显示变体和故事两池进度。恐龙蛋的显示随剧情解锁和历史收藏变化，因此不同存档的恐龙目录总数可能不同。

切换主人后，只显示本人或该角色的收集记录。用掉、放生、卖出或转让后仍保留已收录；角色临时演绎芯片、被别人装载的效果不会算成永久拥有。旧存档通过库存、购买记录及交易回执补录能确认的内容；无法证明的旧收集不补造。记录随 SAR 备份保存。

活动室的暖白图标路牌是设施入口，人名显示在脚下，称号显示在头顶。新档在艾文二星事件后开放「彼方称号」，并获得可选的「听懂风的人」；旧档已有称号保留编辑资格。开放后在仓库切换自己或角色即可修改，最多 12 个字符，可选已获得称号，也可自定义，留空保存可清除。获得称号不自动覆盖当前设置，不改变本名、人设或属性数值。

角色平时聊天的彼方说明会带上当前称号；自主活动可以根据经历保留、修改或清空自己的称号，和原活动使用同一次模型回复，不增加调用。有效活动成功落地后才更新；生成期间用户手动修改的称号优先保留，退出彼方后不接收旧活动的改名。

实现入口：平时聊天在 `utils/chatPrompts.ts`；活动提示词在 `utils/vrWorld/prompts.ts`，由 `runSession.ts` 调用；称号规范、提取和冲突检查集中在 `utils/vrWorld/kanataTitle.ts`。预打包的主动聊天模板不会固化打包时的旧称号。

设置旁的「隐藏」按钮依次切换：只隐藏角色名字与称号、隐藏全部房间文字、隐藏全部角色小人并恢复设施标记、全部恢复。隐藏的设施入口不会留下不可见的点击区域。此偏好随 SAR 本地设置和备份保留。


## 设施引导与分页

水域、布告板、恐龙箱庭、扭蛋机、组装柜、模块商店和随身仓库都提供问号玩法页。第一次打开自动介绍：钓鱼与恐龙由艾文负责，其余由凯恩负责；关闭后记住已读，仍可点问号重看。介绍不调用模型，也不消耗当天个人线话题，已读记录随 SAR 备份保存。隐藏常驻 NPC 时，玩法说明仍可查看，但不出现 NPC 形象。

异界史册与铸造选人支持角色分组、搜索和翻页，每页最多 8 位角色。史册每页 6 条，角色随笔仅在打开该角色时读取，不会一次查询全部角色。没有藏品的角色也能正常选中。随身仓库每页 12 条物品记录，列表上方显示总条数、每页条数和页码，翻页栏随列表滚动保持可见，翻页回到顶部；自己的主人标签只显示「我」。日常三句问候会随台词切换合适表情，已有剧情仍保持原稿表情与包袱时机。

接入彼方的角色会获得 SAR、凯恩和艾文的公共介绍；是否相识仍依据实际活动和记忆。手动与自动活动共用这份介绍，提示词不额外追加「仅手动活动」段落，活动开关仍按用户设置执行。剧情里展示的物品可点击放大，关闭详情会返回原句。

收集图鉴的「收藏 / 专属纪念 / 名册」为同页平级标签，切换时三项始终保留；纪念物详情也在标签下方查看。根页的返回按钮直接回到随身仓库，详情先返回对应列表。

SAR 子页面的顶部操作区统一使用系统的 `--chrome-top`（包含 iOS 安全区及状态栏预留）。模块商店的标题和内容一起避让；恐龙箱庭保留铺满屏幕的背景，操作、场景和详情布局放在安全区内。独立纪念物详情、物品放大及玩法说明也避让顶部；图鉴内嵌详情沿用图鉴标题，不重复增加预留。后续页面不要自行减去固定状态栏高度，也不要仅依赖原生 `env(safe-area-inset-top)`，以免绕过 iOS 独立运行时的兜底值。
