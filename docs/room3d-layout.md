# 家具布局操作手册

用户确认的规则（2026-09-21）：所有房间、样板房及自动布置都必须先读本规程。家具不能随机分散摆放；先确定功能分区，再按真实使用关系成组摆放。不能把逐件寻找空位或通过碰撞检查当成设计完成。

## 布局优先级

1. 功能分区合理。
2. 家具之间存在明确的使用关系。
3. 动线连续且无遮挡。
4. 视觉构图平衡。
5. 最后才考虑填补空白；允许留白，不以填满房间为目标。

判断位置必须问：**现实中的人会不会把它放在这里，以及人在使用它时是否方便？** “这里能放下”只是最基础的碰撞条件。

## 先分区，再放组合

- 先标记入口、门扇/柜门开启范围、窗户、主要通道，再确定各功能区占用哪一段墙面。
- 家具优先沿墙和功能区成组排列；中央保留宽敞、连续、容易行走的空间。不能把家具平均分散到各个位置。
- 同一组合内的家具优先靠近；不同组合之间应有清晰的空间边界。家具朝向必须服务于组合的使用关系。
- 先放组合里的主要家具，再放配套家具与摆件。组合整体不适配时调整分区或减少物件，不把其中一件随意塞进别区。

## 家具组合模板

| 组合 | 家具 | 必须满足的关系 |
| --- | --- | --- |
| 厨房 | 冰箱 + 橱柜操作台 + 水槽 + 灶台 | 集中在同一侧墙面附近，连续或接近连续；灶台不单独远离橱柜，水槽不脱离主要操作区 |
| 中岛 | 中岛 + 1–2 个座位 | 属于厨房区域，平行于主橱柜；留出合理通道，不随意旋转，不阻断冰箱、灶台、水槽间的路线；座位放在就餐侧 |
| 客厅 | 沙发 + 茶几 + 电视/电视柜 | 沙发与电视对应，茶几在合理取用范围；形成独立休息区，不能孤立贴在中岛旁或挡住厨房工作动线 |
| 阅读 | 书桌/小桌 + 椅子 + 灯 | 椅子面向桌面，灯服务桌面；留出坐下、起身及椅子后退空间 |
| 装饰 | 植物/摆件 | 用于边角或所属家具的台面，不占主要动线，不为填空而摆 |
| 洗漱 | 洗手台 + 镜柜 + 毛巾柜 | 沿同一墙段组织，镜面面向使用者，毛巾在附近；台前留出站立空间 |
| 洗浴 | 浴缸/淋浴 + 毛巾架 + 地垫/沐浴凳 | 集中为湿区，取用物件靠近；保留进出淋浴、浴缸侧边站立及擦干的位置 |
| 洗衣 | 洗衣机 + 洗衣篮 + 洗涤用品/收纳车 | 靠近成组，用品落在真实承托面；机门前留空，洗衣篮不堵装卸衣物位置 |
| 如厕 | 马桶 + 周边使用空间 | 靠墙布置，面前及侧边留空，不摆在入口或中央主通道 |

## 配色与验收

- 本轮整套住宅统一采用 **黑 × 绿 × 白**。卧室已确认的奶油绿白、厨房的黑色是同一套配色的不同占比；浴室继续沿用，不另加粉紫或蓝色主题。原有项目原木材质仅作少量辅材。
- 先定墙地底色、柜体主色和强调色，再给家具分配颜色，不能每件家具独立选一种颜色。
- 碰撞检查通过后，仍须检查组合关系、朝向、开门/取用空间、主要通路，以及 chibi 身体和整个头部的实际占用。
- 用真实场景查看全屋和另一侧视角。检查入口到各功能区的连续通道，不能靠瞬移掩盖不合理布局；互动的瞬移兜底不等于布局验收通过。
- 新预览与已有用户房屋存档分开；未经要求，不用重排模板覆盖用户的正式存档。
