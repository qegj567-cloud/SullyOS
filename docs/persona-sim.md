# 查手机 · 人格模拟与生活记录

「用 TA 的手机活一次」生成的完整小剧场保存在角色的 `phoneState.simLogs`，随角色备份导出和恢复，不需要数据库升级。

## 保存与续播

- `CheckPhone.runSim` 生成成功后立即归档完整 `script` 和可读梗概，再发布全局 `ready` 通知。生成期间离开查手机也会归档；归档只保留体验，不写入角色聊天或情绪状态。
- 全局 `personaSimStore` 只负责生成进度和跳转通知。开始播放后消费通知，不删除已经归档的剧本。
- 新记录的 `playback` 初始为 `{ beatIndex: 0, status: 'ready' }`。每次切换段落都保存当前下标和 `playing` 状态，不依赖退出按钮、卸载或浏览器关闭事件。
- 中途退出后，小剧场入口展示最近一条未完成记录；生活记录可选择任意未完成记录。两处都提供「继续上次」和「从头播放」。继续会重新显示退出时的当前段落，自动播放默认暂停。
- 播到 `end` 后更新同一条记录为 `completed`；不会新增一条重复记录。未完成记录先显示进度，隐藏结局和收尾摘要。
- 更新必须用 `updateCharacter` 函数式合并最新角色状态，保留并发写入的其他手机数据；进度按记录 ID 修改，同一段只保存一次，避免上下文更新引起重复写入。
- 全局通知按 `charId` 匹配，切换机主时重新挂载播放页面，避免把另一角色的剧本或断点带过来。

## 完成效果与旧记录

`completedAt` 只记第一次看完的绝对时间戳，属于用户体验记录。首次到结尾才按角色日程功能开关施加情绪效果；从头播放或续播已经看完过的剧本都不再施加。重播可以重新保存断点，但保留第一次完成标记。

旧版只在结尾保存记录，因此没有 `playback` 的旧记录一律视为已经看完。带剧本的旧记录仍可重播，第一次重播时补齐完成标记；没有剧本的旧记录仍只能发送给 TA。已经删除的记录不因播放更新自动恢复。
