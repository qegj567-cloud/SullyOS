# 3D 家具导入规程

设计或重排房间前，必须先读 [布局与功能分区操作手册](room3d-layout.md)：先分区、再按家具组合布置，碰撞通过不代表位置合理。

用户确认的固定流程：**GLB → 清理图片贴图 → 按部件自行上色 → 减面/平滑 → 按 chibi 尺寸实装验收**。适用于今后收到的家具模型，不仅是座椅。座椅另须遵守 [坐姿规程](room3d-seating-assets.md)。

整屋素材追加约束：按整件家具粗拆，连排柜保留为一组；每件全部材质合计严格少于 4000 三角面并平滑。浴室外围假山排除。五套样板房的提取、修补、门与无图壁纸/地板见 [样板房规程](room3d-showrooms.md)。该约束适用于这批新增素材，历史资产不在本次重新减面。

## 素材处理

1. 记录原文件体积、三角面、顶点、材质/图片数和包围盒。先读取几何，外部原文件不直接进入 public。
2. 删除图片、纹理引用、UV 和未用数据；不能采样 AI 图像做顶点色、烘焙图或新贴图。材质颜色由几何部件含义人工指定。木质统一现有茶几的 `woodLight`（线性 RGB 0.8227857351 / 0.5972017646 / 0.3915724754）。
3. 原模型的桌上物件拆成独立 `tabletop` 家具。融合网格不能简单切掉就交付：空台面要补平，缺失的隐藏面重建。雏菊桌重建封闭花瓣台面；书本因原模型与茶杯融合，改用封闭的书页块及封面。
4. 根据轮廓减面，保留叶片缺口、杯柄等识别细节。平滑法线，必要时保留硬边。不要给已经很轻的模型无意义增加细分。
5. +Y 向上、底部 y=0、水平中心 x=z=0，按场景/chibi 比例确定尺寸。设置真实碰撞包围盒、颜色可编辑部件、桌面 support；花瓣轮廓的有效放置范围使用保守内切圆。
6. 合并同材质网格，复用加载模板。GLB 自包含、无图片和 UV；小型家具通常控制在 2–6 千三角面，超过要有视觉理由。动作复用主渲染循环，停止时不再持续刷新。
7. 验证正面/侧面/背面，桌上物件移动、旋转、收纳、撤销；检查贴图清零、面数、重复操作的 GPU 资源，以及 chibi 的头和短手。

## 绿植交互

**浇水能力约束：`surface === 'floor' && waterable === true`，两项缺一不可。** `isWaterablePlant` 保留为浇水入口及旧放置类别的判断。新家具架的「花草绿植」用途分类包含花瓶、桌面盆栽和落地植物；归入该分类不等于拥有浇水动作。今后新素材必须按此规则标记，不能按名字猜测。目录中的 `waterable: true` 只授予已验收的植株。`wateringSpot` 顺序检查前、右、后、左，预留身体和整个脑袋的空间，并检查地板边界、家具与墙段。四周无空位时按钮禁用，不强行穿过去。当前是「小人 → 给绿植浇水」手动到位，尚未接自主寻路/多人占位。

浇水持续约 4.4 秒，小手仅刚性移动，临时水壶与七滴水使用纯几何。结束收起道具；切换动作/坐下、切房间、收纳植物会取消。移动植物后重新寻找有效位置。减少动态效果设置下展示静态动作。交互状态不写入家具/角色存档。

- `art/jellyfish-home/botanical-qa.mjs`、`utils/room3dWatering.test.ts`：资产预算、四侧空位、桌面挂载、浇水生命周期和资源复用检查。
- `test/fixtures/room3d-botanical.html`：可直接查看的组合验证场景。正式初始房间仍由 `createHome` 管理，新素材通过家具架选取。

## 原木窗与电视组

`pnpm node art/jellyfish-home/media-assets.mjs` 使用 `sources/wooden-window-geometry.glb` 和 `sources/gaming-nook-geometry.glb` 重建；两个制作源均已去掉图片和 UV。窗户保留原木窗框与把手，四片浅蓝实色磨砂窗面不透出背后的实体墙。仅输出一个 `wooden_window`，`surface: 'wall'`，由摆放位置决定朝向，不再按后墙/左墙分素材。

`wallMount.js` 枚举真实墙面：原房屋保留的墙段，以及新增高墙的可用面；同面相邻高墙合并可挂宽度。空边、矮墙、栅栏不挂窗。程序移动按最近墙面吸附，指针拖动对真实墙面求交，跨墙时自动转向并限制窗框不越过墙角/上下沿，放下仍检查家具碰撞。原 `wooden_window_left` 存档迁移为统一 ID，保留实例 ID、配色、高度及左墙朝向。拆除/收纳/移走承托墙后，失去墙面的窗户一并收纳；撤销恢复。

外墙窗户现接入室内日光：依据实际朝向从窗内向地面投射柔和四格光斑，可照亮桌面并被家具遮挡。移动、升降、换墙、收纳、撤销及换房同步光源；显示上隐藏墙面仍保留采光，室内隔墙和相邻房间共用墙不生成室外光。窗玻璃保留不透明磨砂材质和少量暖色自发光，不切割墙体几何。四格遮罩由代码生成，非 AI 图片。桌面清晰档最多两扇，均衡/触屏最多一扇，省电/总览不投射；优先当前房间，再选已细绘的同层房间。

电视和电视柜按已检查的连通片拆开，删去旧游戏机、手柄及柜内杂物，柜顶补封闭平面。电视柜目录提供矩形 `support`，电视、主机、手柄都是独立 `tabletop` 物件，移动/旋转柜子跟随，单独收纳互不影响。游戏主机和四色手柄完全以代码重新建模（圆角外壳、摇杆、方向键、四色按键、接口与通风槽），不复用原游戏机的形状或图像。

新资产用目录 `paintMaterials` 明确哪些材质允许用户换色，例如柜子只换奶油柜门，保留木色、金属把手与电视屏幕；旧资产继续兼容现有规则。所有几何按材质合并，窗户每款 4,146 三角面，电视柜 839，电视 322，主机 3,300，手柄 2,204。当前交付的是静态家具，电视节目/游戏动作没有接入。

验证：`art/jellyfish-home/media-qa.mjs` 检查无图片/UV、面数体积、木色、分类、承托、旋转跟随、独立收纳、配色和撤销重做；`test/fixtures/room3d-media.html` 为隔离场景，带返回原捏人小屋的入口。日常预览留在 `/chibi-experiment.html`，不要把隔离验证页当成完整捏人入口。

## 鲸鱼阁楼床侧挡板修复（2026-09-16）

原制作源只有床头板和正面星星护栏，两侧未建挡板。现补齐奶油色圆角侧挡板及原木压边，楼梯侧保留前段上床开口；挡板属于床模型，不随房屋墙面显示切换。原占地、家具 ID、摆放坐标和床下空腔不变。

`build.py` 保留对应制作源；缺少原 `.blend` 时运行 `pnpm node art/jellyfish-home/repair-loft-guards.mjs` 对 kit 添加几何，幂等标记阻止重复添加，不重写其他资产。增加 432 三角面、两个材质绘制组，复用已有纯色材质。`room3d-loft.html` / `loft-guard-qa.mjs` 检查正背面、楼梯开口、无墙模式、收纳及撤销。

## 浴室与所有家具改色

浴室的拆件、破损洗衣机重建和承托要求见 [浴室家具规程](room3d-bathroom.md)。所有家具必须声明并验证实际存在的主体换色材质；预设、自选颜色、恢复原色均按实例保存，支持撤销重做，不污染共享材质。

卧室模型还需遵守 [卧室与玩偶规程](room3d-bedroom.md)：床面和大头空间必须实测，玩偶按可抱持家具处理，保持满怀的体积与独立原位置。

## 家具架分类与动作标记（2026-09-17）

`apps/room3d/furnitureCatalog.js` 统一维护展示分类，独立于 `surface`、旧 `furnitureType`、承托/碰撞及互动能力。素材重新导出不会覆盖分类。现有 115 件均有明确用途；新增素材必须补充 `USE_BY_ID` 并通过全目录覆盖测试。

- 按房间：客厅、电竞、厨房、浴室、卧室。电视、电视柜、沙发和茶几归客厅；原模型集合 `collection` 不必为了展示重写。
- 按用途：桌椅沙发、床铺寝具、柜子收纳、厨房用品、卫浴用品、家用电器、电脑娱乐、灯具照明、装饰摆件、花草绿植、地毯布艺、宠物用品、户外庭院、特殊设施。每件有一个主要用途，两种分类互相独立。暂缺素材的类别保留空状态；墙、门仍从「建造」进入。
- 玩偶属于装饰摆件，抱持能力仍由 `holdable` 决定；电视柜虽能承托电视，也归柜子收纳；花瓶/盆栽均可浏览，但只标记已接入浇水的植株。
- 缩略图右上角「动作」根据已实现的坐位、床位、抱持、浇水、设备活动、冰箱开关和现有餐桌活动显示；无坐位的旧椅子、无躺位的旧床、尚无洗浴动作的卫浴不会误标。组合动作说明搭配条件；悬停预览或选中已摆放家具可以查看动作名。收纳箱沿用同一标记。
- 手机用途选择使用下拉框，避免 14 类挤掉预览；桌面显示完整分类按钮。分类和筛选不修改房屋存档、物件数量或运行时互动规则。

### 下一轮互动需求（已确认，尚未实施）
用户本轮明确「先把分类做好」。后续吃饭入口改为已摆放餐具的位置，不再绑定专用餐桌型号；任意适配的桌椅可自动吸附，桌椅搭配电脑触发玩电脑。落地前仍需根据真实坐位/桌面/餐具坐标检查头部、手的可达范围和周围空间；当前餐桌与电竞桌的既有判定保持不变，不将新规则当作已完成功能。
