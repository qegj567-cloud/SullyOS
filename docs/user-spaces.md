# 用户空间实施契约

## 已确认需求

- 用户在个人档案中创建、切换用户空间。角色、群聊、历史、记忆、印象、桌面内容和玩法存档隔离；旧数据属于默认空间，新空间可无角色。
- 不判断人设是否属于同一个人。只说明：编辑资料延续经历；另一个身份使用新空间。角色专属的名字、外貌与补充设定仍属于当前用户，不分出第二套记忆。
- 系统设置共用，不要求重配 API、代理、语音、记忆服务。依赖角色的授权与选择按空间保存；切换后提醒，空选择不回退全部角色。
- 神经链接可从另一空间继承角色。复制配置、外观、手办、布置及依赖，生成新角色 ID；不带聊天、记忆、对旧用户的印象、相处衍生状态、任务或处理水位。不修改源角色。
- 二进制素材共用，配置独立；修改素材产生新文件。删除不得伤及其他引用。导出同一素材一次，导入去重。
- 多用户时备份先选当前用户 / 所有用户，再选原有整合、文字、媒体样式；单用户跳过范围选择。单用户包必须自足，旧备份保持兼容。

## 实现边界

每个页面会话固定所属空间，切换通过重新加载终止旧运行环境。主库和协同库按空间分库，默认空间保留旧库名。localStorage 在启动时装配固定空间的视图，共用设置使用原键；其他键按空间隔离。不得在异步回调中动态跟随后来选中的空间。

手动切换与新建空间使用连续过场：淡出旧页面，显示目标用户名字与首字标识，目标桌面就绪后淡入；底层仍销毁旧页面环境。本次有效切换略过普通开机动画与点击锁屏，普通启动不变。过场由 HTML 内联脚本接续，sessionStorage 只保存一次性的目标 ID、名字与短期时间戳；目标不匹配或过期不接续，不携带角色、记忆、头像二进制。减少动态效果时取消动效延迟；启动错误、数据库失败或超时释放遮罩，不遮挡恢复入口。通知跳转继续沿用既有路由。

素材池跨空间，源文件和引用分离。跨空间继承不经过公开角色卡剥离流程，避免丢失用户美化与配置。复制操作提交前整理全部关联，失败不留下半个角色。

主动消息的全局连接、收件箱与云端管线不变；角色 ID 全局唯一。前端切换不暂停任何空间的角色、不修改排程、不要求更新 Worker。所有角色照常发送，点击通知按角色归属进入对应空间。其他空间的回程不得被当前空间确认或删除。

## 代码与实际行为

- `utils/userSpaces.ts` 在 `index.tsx` 的第一个静态依赖中安装 localStorage 视图；`appEntry.tsx` 随后启动原应用。`utils/db.ts` 按空间复用连接，协同库同样分库。默认库名不变；目录在默认库 assets 中留镜像，localStorage 丢失后恢复目录并进入默认空间。
- 个人档案的「用户空间」新建/切换后重新加载，避免旧请求写入新库。系统 API、代理、音乐连接、语音、记忆服务及已读系统介绍共用；桌面外观、角色目标快捷入口、玩法和历史独立。新空间不补默认 Sully。
- 个人档案「在 TA 面前的我」选择角色后统一设置专属聊天头像、名字、外貌和补充设定；头像沿用 perCharAvatars，文字沿用角色 userPersona，不迁移已有数据。共享 ContextBuilder 在「互动对象 (User)」中合并角色视角资料，聊天、见面和电话共用；群聊公共用户资料不变，成员上下文各带自己的补充。神经链接的「新建链接」仍直接新建角色；有其他用户空间时，在按钮下方显示小号文字选项「从其他用户载入角色」。
- 神经链接「继承角色」生成新 ID，清空经历、水位、旧用户印象、电话记录、家园关系与后台任务；保留手办/模型/语音/家具/独立 API 等配置，世界书和可编辑素材元数据复制为新 ID。源记录只可能做等价的图片引用规范化，不改源角色设定或经历。
- `blob_assets` 位于默认库，是共享不可变文件池；内容散列对应唯一二进制，旧素材编号保留为轻量别名，MIME 按引用保留。跨空间 GC 和显式删除检查所有空间、协同库及本地配置。陪伴语音继承使用共享 blobref，旧 Blob 记录仍兼容。
- 继承与删除通过 Web Locks 协调，删除在继承提交引用后重新扫描；无法跨标签协调时，多用户下保守保留文件。扫描也检查浏览器现存的空间数据库，目录意外丢失不会直接把其他空间素材当垃圾。共享编号禁止被不同内容覆盖，并在写事务内再次检查并发冲突。
- 优化资源存储从扫描素材、迁移图片到合并引用提交，全程持有同一共享池独占锁。清理等待提交后重新检查引用，避免去重准备复用的旧图被中途删除；仅靠新图的 72 小时回收豁免不能保护旧图。页面内维护锁继续负责即时提示重复操作。
- 多空间导出先选当前/所有用户，再选择整合/文字/媒体。新包以 `user-spaces.json` 为目录，每个空间的主库与协同库分页保存，`shared/<hash>.bin` 去重；当前用户包不引用被排除空间的表。文字保留向量类型，媒体补素材而不覆盖已有文字/记忆，活动 canvas 的 data URL 还原格式不变。只有一个空间时保持原导出格式；旧包在当前空间恢复，跨空间角色 ID 冲突会拦截，避免云端串号。
- 设置 → 备份与恢复提供「从其他网址 / App 迁入独立用户」。每个来源用户自动新建空间，支持旧 JSON、v1/v2/v3 ZIP 和新版多用户包；整合或文字备份均可，媒体补图包不能单独创建完整存档。普通恢复入口保持原编号与恢复目标，冲突时提示使用迁入入口。
- 独立迁入保留聊天、记忆、玩法、协同文件和原始时间；角色、记忆节点与共享素材别名获得新编号，群成员、记忆向量/连线、水位、角色相关键、家园私聊线程及图片引用随之调整。聊天正文、名字和提示词不按编号做全文替换；缺失图片也获得独立引用，不借用本机碰巧同编号的另一张图。
- 迁入沿用目的地系统 API / 后端连接，不覆盖全局设置，不接续来源云端任务或待收结果；迁入角色的主动排程、即时对话与离开后消息均关闭，用户可再开启，避免首次重载按旧聊天触发补发。历史和长期记忆不会像「继承角色」一样清空。完整预检后才写入新空间，全部成功才公布用户目录；失败仅回收本次分配的新空间，原用户不作为回滚目标。
- 导入预检目录、分片、记录主键、文件和素材编号冲突后才写数据；每个数据库事务原子提交。浏览器不支持跨多个 IDB 数据库的总事务，因此配额或系统中断仍可能造成跨库部分完成，需保留原备份后重试。定位区域、原始坐标和定位 Key 不进入备份；Worker 连接仍走原有单独选择与恢复确认。
- 切换后的提醒提供位置可见角色、天气城市和已启用 MCP 的聊天选择。新空间的位置和工具默认为无人可用，稍后设置不会扩大授权。
- 切换不调用主动消息 Worker，角色的启用状态、任务、生成和推送保持原状。通知点击统一查角色所属空间，必要时重新加载并恢复聊天目标。补收仍把各空间正文放进全局持久收件箱；聊天落库和后台结果处理只由所属空间认领，其他空间不销账。没有当前空间的角色不会被自动删除或停用。
- 共用 API 变更后的凭据同步覆盖所有空间的角色；全局工具配置合并各空间的天气城市和 MCP 角色授权，不能用当前空间覆盖其他角色。旧 MCP「全部」仅展开为其所属空间的角色，新空间仍需选择。云端清单的本机角色对账也涵盖所有空间。
- 浏览器原生 storage 事件按当前页面所属空间转发，其他空间的私人事件不可进入本页监听器。内嵌捏人器使用带空间编号的草稿键，同名角色也不会串草稿。
- 「格式化」明确清除所有用户空间和共享素材，沿用已有的云端清理/失败确认流程。删除单个用户只在「档案 → 用户空间 → 管理用户」中显式执行。

## 删除用户

- 当前用户必须先切换；至少保留一个用户。连续两次警告各等待 10 秒，只计前台停留时间，取消重开从第一步重新计时。
- 页面持有所属空间的 Web Lock；删除要求独占且不等待，有其他页面打开目标用户时拒绝。缺少 Web Locks 时不执行删除。删除开始后的持久标记阻止进入、继承和通知跳转到目标用户；失败后在管理中「继续删除」。
- 先逐角色提交云端 `retire-owner`，旧 Worker 不支持或请求未确认时保留本地存档。已受理项记录进度，重试不重复停用；云端已建立停用屏障、仍在清理时明确提示后台继续。若配置了远程向量库，按 `char_id` 精确删除，不调用全表清空。
- 清空目标主库所有私人表、协同工作库、私人 localStorage 与内嵌捏人草稿；主动消息只清理目标角色的收件及回执，不清理全局连接、订阅或其他角色。默认用户被删除时保留默认库的共享 `blob_assets` 与用户目录镜像。
- 只回收目标内容曾引用、且经所有存档/配置重新检查已无人引用的素材；仍被其他用户引用的图片、模型、语音保留。素材检查失败则保留文件并提示，不冒险删除。
- 删除成功后保留无个人内容的删除标记和空数据库结构以阻止迟到写入；完整备份可显式恢复已删除用户，进行中的删除须先完成，媒体补图包不能恢复已删除身份。外部备份不自动删除。

## 载入与切换提示

一次性「多用户空间来了」公告排在全局更新队列最前，沿用数据就绪、解锁与启动提示门禁。明确关闭、返回、知道了或去档案后，写入全局已读键 `sullyos_update_user_spaces_v1_seen` 并结束本轮公告队列；切换用户不重复提示。去档案只打开入口，不代替用户新建、切换或更改资料。已读键加入本地镜像，公告不新增网络请求或埋点。

「从其他用户载入角色」保持在「新建链接」下方，按来源角色分组展示，支持整组与全部勾选；已失效的分组归入「未分组」。切换来源立即清空选择，晚到响应不能覆盖新来源。

切换提示简化为「角色和记录已切换，系统设置不用重配。」只有实际可配置的感知或工具角色授权才显示保存/稍后设置；空空间仅显示「知道了」，关闭不改写授权。

## 验收

导出时某份引用素材已不存在，只跳过该文件，继续打包其余文件、记录和原引用，不修改本机数据。完成后设置页保留缺失数量与位置提示；ZIP 根目录的 `缺失素材清单.txt` 和 `diagnostics/missing-assets.json` 记录缺失编号，多用户包同时在 `user-spaces.json.missingAssets` 留下可选清单。多用户导出按实际包含的用户、记录及字段定位，每份素材最多列五处；嵌套 JSON / CSS 中的引用也会检查，不记录正文或 API 配置值。旧单用户路径沿用跳过缺图的行为并补清单，没有位置资料时明确说明。纯文字包不检查被剥离的素材；真实数据库读取、文件打包或压缩异常仍报失败，不能当成缺图跳过。旧包与没有缺图的新包保持原格式兼容。

云端备份按所有用户保存，避免自动轮换备份只剩最近使用的空间；手动 ZIP 导出沿用用户所选的当前/全部范围。

- 旧库无迁移丢失；新空间为空；来回切换恢复自己的角色、桌面与原文。
- 延迟写入留在源空间，多标签页不会跟随全局选择串写。
- 角色继承新 ID、无记忆/印象/运行状态，外观和配置完整，世界书独立编辑。
- 素材引用复用，删除一方不损坏另一方；备份共享文件不随用户数量倍增。
- 三种导出样式的当前/全部范围恢复，旧备份兼容，异常包在写入前校验。
- 实时感知选择按空间恢复，空角色与稍后设置不误授权。

## 本轮验证记录

已在独立本地预览中完成：新建空空间、切回原空间、继承 Sully、检查零记忆、编辑角色视角称呼，以及设置页先选用户范围再选导出样式。截图保留在本轮工作附件中。自动回归覆盖跨库主键隔离、迟到写入、角色配置复制、共享图片/语音、跨用户删除保护、三种备份往返、桌面内嵌图片、媒体补图保留新正文/日程/家园记录，以及云端结果和本地收件保留给所属空间。

彼方的独立 API、活动间隔和排除范围随角色配置继承，书签、批注、当前活动和临时模块不继承；新角色的彼方接入保持关闭。明确选择的书籍、分类及其中书籍作为依赖复制为新编号；空分类仍保留，没有可用书时仍沿原规则处理，分类范围绝不自动扩大。角色分组也复制定义；不复制群聊关系。配置引用的编号重映射不改写同名的角色名字、提示词或 CSS 文本。

本轮未部署远端 Worker，也未使用真实模型凭据发起生成。全项目 TypeScript 检查存在既有错误（例如 PersonaSim 和房间类型）；生产构建与针对性测试单独验证，不能把构建通过解释为全仓类型检查无误。

复查补齐通知按角色归属跳转、跨空间凭据与工具配置合并、角色分组和阅读依赖继承、原生 storage 事件及捏人草稿隔离，以及共享素材并发保护。22 个相关测试文件共 638 条用例通过，生产构建通过；本轮修改文件无类型诊断。主动消息 Worker 业务代码与版本号保持原样，未做真实远端推送端到端验收。

补充本地检查：`scripts/amsg2-e2e-harness.mjs` 的 126 项断言全部通过，使用正式 Worker bundle、真实 SDK/HTTP/SQLite 与 Web Push 加解密；模型回复及推送接收端由测试工具模拟。这不代表真实浏览器通知投递端到端验收。用户空间、通知路由、主动消息运行时与补收的 5 个测试文件共 257 条用例再次通过。按用户后续要求暂停真实云端验收，启动本地构建预览供界面检查。

切换过场补充验证：过场脚本、启动恢复和用户空间的 3 个测试文件共 30 项通过，生产构建通过。本地浏览器新建空「切换预览」空间并返回原用户，观察到过场接续后直接进入桌面、原用户的两位角色恢复；普通刷新仍经过原开机/锁屏流程。测试空间保留为空，未发送聊天或配置云端任务。

用户管理补充验证：分组选择与来源切换竞态、两次前台倒计时、默认用户删除与共享素材保护、云端失败续删、精确远程向量清理、目标收件箱清理、备份恢复及新建/删除并发均有回归。相关用例合计 178 项通过（并行构建期间备份测试触发超时，隔离重跑 13 项全部通过）。全仓类型检查仍有既有诊断，本轮修改文件无诊断。真实页面验证了整组勾选、第二次独立倒计时与简短提示；未在用户页面执行删除或发起云端清理。
