# 内置 SULLY 主题图标补齐

`utils/builtinAppearanceUpgrade.ts` 在启动加载完桌面图标后，后台补上内置 SULLY 主题缺失的哔哔图标，不重新应用整套主题，也不阻塞桌面打开。

旧版没有记录已应用的内置主题 ID。升级比对聊天、神经链接、美化三个图标的原始文件 SHA-256，至少两张与内置素材一致才识别为 SULLY 图标组；支持本地 Blob 引用、旧 data URL 和内置素材路径，不请求用户自定义图片的网址。只改过其中一张仍能补齐；三张中改过两张则无法可靠识别，需要重新应用主题。

- 哔哔已有自定义图标时不替换。壁纸、颜色、组件、其他图标均不变。
- 新图片先下载并校验，再保存为正常的 `blobref`，随原有图片备份和离线存储使用。
- 写入时在同一个 assets 事务中再次检查原图标及升级标记，防止下载期间切换主题、改图或另一个标签页的操作被覆盖。
- 图标与 `builtin_sully_bibi_icon_v1` 完成标记一起提交。失败不标记，下次启动重试；成功后不再补回用户移除的图标。
- 用户通过图标设置手动更换或移除哔哔图标时，同样记录这一轮补齐的退出标记。

测试：`pnpm vitest run utils/builtinAppearanceUpgrade.test.ts`，覆盖旧 Blob 存档、部分自定义、其他主题、保留已有图标、下载与校验失败、并发修改及多标签页。
