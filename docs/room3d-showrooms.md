## 样板房入口

「房间」或「扩建」面板下方可追加：原木温泉、奶油书房、黑白原木厨房、奶茶客厅、暖木卧室。

`apps/room3d/showrooms.js` 在当前房间同层的相邻空位追加一间，优先右、前、左、后，上层仍需下方支撑。已有房间、家具和自定义颜色不覆盖；四周占满时报错，不自动替换或拆墙。采用副本准备数据，再通过编辑器同一 `commit` 提交，因此失败、撤销、重做、保存和手机容量限制都走已有机制。

每套初始六件家具（部分复用已有校准家具），为 chibi 留通道。外侧前边没有邻屋时配置 2.2 宽门洞；邻屋间继续由用户在建造模式修改隔墙。门洞和各家具均能继续编辑。手机最多五块房间面积，初始房间也计数，不为样板房另开容量豁免。

壁纸新增「竖木护墙」「厨房小方砖」「温泉石裙墙」，地板新增「错缝石砖」「拼花木地板」。纹样由共享材质的数学公式生成，不下载图像，也不逐块建立网格；房间独立保存样式与颜色。

`showroom-door.glb` 将门框/蝴蝶结与门扇分别导出。建造模式新增「蝴蝶结心窗门」，宽度跟随门洞，小人靠近时转动门扇，复用已有路径与开门机制。整个模型而非每个组分别校验 4000 面预算。

## 制作与复现

- `showroom-parts.mjs`：整件裁切范围、比例、人工配色与用途。
- `showroom-assets.mjs`：空间裁切、减面、修补、平滑、材质合并与目录导出。默认从 `sources/showrooms/*.glb` 干净制作源重建。`--extract` 才读取 `output/showroom-source/{2..6}.glb`。
- `showroom-door.mjs`：默认从干净门源重建；`--extract` 从编号 1 的原模型提取。
- `sources/showrooms/manifest.json` 记录制作源 SHA-256，`raw-report.json` 记录原始文件指标，`assets-report.json` 记录家具最终面数和体积。干净制作源也没有图片/UV/颜色属性。

运行 `pnpm node art/jellyfish-home/showroom-assets.mjs` 和 `pnpm node art/jellyfish-home/showroom-door.mjs` 即可复现，不需要原 AI 贴图或联网。
