# 叠穿辅助整理

衣橱的「一键整理叠穿」会临时隐藏外套覆盖下的内搭三角面，将衣身与肩根残留的穿插局部收进外套，并在搭配裤子/裙子时为上衣和外套衣摆留量；默认关闭，开启后随换装、版型和体型更新。点「恢复整理前」关闭自动处理，恢复手动版型。开关保存在 `HairSettings.wardrobeLayering`，沿用草稿、保存搭配和撤销重做；小屋 `createVisitor` 使用相同加载入口。

## 水手领收进外套（2026-09-21）

用户确认：水手领搭配连帽外套、翻领西装、系带长外套时，**收在外套里面，中央开襟继续露出领子**。按 [Character Creator 的 Tuck In / Keep Outer](https://manual.reallusion.com/Character-Creator-5/Content/ENU/5.2/04-Introducing-the-User-Interface/Cloth-Layer-Settings.htm) 分开处理穿法与碰撞；不是猜测所有领子都该藏起。

- `garmentCollar.ts` 是这六组搭配的明确版型规则（长/短袖水手服 × 三款外套），不是所有服装通用的布料模拟。宽水手领的胸骨绑定侧片/后片向颈部收拢，中央领襟保留；白色袖根单独用实际外套曲面作局部内收。开衫及其他已认可搭配不启用该规则，透明外套保守跳过。
- 修正使用共享的 `apps/room3d/chibi/approvedStandingPose.json` 固定试穿姿势，预览动作与缩略图也引用这份数据。将各原顶点按其原骨骼权重变到该姿势，查询 BVH 后用**该顶点混合蒙皮矩阵的逆**还原位置，不修改权重、不增加衣料顶点、不触碰正在播放的骨骼姿势。衣物整体宽松、袖口、已修衣摆仍走原逻辑。
- 内收前补肩侧整面皮肤遮挡，依据实际外套覆盖，保留中央脖颈与头部；遵守外套的自动皮肤遮挡开关。最终通用身体遮挡在这些搭配的肩部禁止继续细分：旧边界插值会让肩部新蒙皮面偏离原身体，形成额外皮肤碎片。下半身/鞋袜仍保留原边界处理。
- 不改变发布 GLB、贴图、UV、外套形状或当前角色实例；关闭整理/脱下外套后从缓存母版精确恢复。新增 `garmentCollar.test.ts` 检查六组实物搭配的肩领穿插、中央开襟、颈部保留、外套/袖口及蒙皮不变、恢复、透明材质、自动遮挡开关和计算不依赖当前动作。

普通站姿正面肩领采样（步长 0.012，排除中央开襟）中，旧算法长袖三组为 267 / 87 / 289 个穿插点，短袖为 209 / 60 / 206；新规则为 7 / 0 / 5 和 0 / 0 / 0。停用新规则的负对照六组均无法通过回归。残余小边角及大幅动作仍有局限，不宣称全角度零穿模；叉腰、侧面和背领另做实物检查。

验收：84 项服装/版型/颜色/换装/鞋袜/姿势测试与衣橱生产构建通过。实际页面确认袖筒文案、换装及开启整理后角色实例 ID 不变、保存重开仍启用整理、无浏览器错误。范围 TypeScript 检查仅剩既有 `mirrorMotion.js`（两处）、`diningMotion.js`、`rhythm.js` 声明缺失；新增代码无类型错误。

## 裤腰 / 裙腰与下摆张开

上衣与下装叠穿采用 [CC Pull Out / Keep Inner](https://manual.reallusion.com/Character-Creator-5/Content/ENU/5.2/04-Introducing-the-User-Interface/Cloth-Layer-Settings.htm) 的方向：保留下装形状，向外放上衣衣摆。使用现有 BVH 查询实际拟合后的几何，不根据“裙子”或“裤子”名字猜宽度。

- `hemOpening` 为上衣/外套独立的 0–100%「下摆张开」强度，0 保持原版型，100 在衣摆末端增加最多 45% 径向尺寸。变化在衣摆以上 0.65 × 身高范围内平滑消失，最高不超过 2.85 × 身高，肩胸、袖型与衣长不变；旧草稿缺省为 0。保存、撤销、重置走既有版型字段。
- 手动下摆值按上衣/外套 ID → `hemOpeningByBottom` → 下装 ID 保存；外套配连体使用连体 ID，无下装用 `none`。没有记录的搭配为 0，其他尺寸仍按整件共享。换下装前将旧草稿的全局 `hemOpening` 绑定到当前搭配，保留旧外观；重置只清当前搭配的下摆并重置共享尺寸，其他搭配的下摆值保留。预览与小屋共用 `fitForGarment` 解析。
- 一键整理现在也支持只有上衣 + 下装的搭配。`garmentHem.ts` 在已拟合的裤腰/裙腰附近，从外向内查询最外表面，包括腰带/褶皱/纽扣。检查上衣原顶点、三角面边中点和重心，并从下装顶点/面心的真实高度反查上衣原三角面，补足稀疏网格之间的小腰扣。
- **水手服衣摆误撑修复**：不能将裤腰上方的衣料下投到腰口检查，否则水手服内部封口会被误判穿进裤子，产生两侧翘边。现在只在真实高度出现径向重叠时补留量；已存在正间隙就不强求扩大到目标间距。边中点样本中权重为 0 的另一角也不再接收放量。
- **局部接触修正替换整圈包络**：旧算法将某方向的最大位移延续到整个下摆，使腰部一点重叠撑开原本宽松的开衫下角。现在每个接触仅约束原三角面的支撑顶点，按重心权重与离腰口距离分配最小二乘位移，相邻面仅通过共享顶点跟随；不再沿方向或高度传递统一放量。最大单顶点位移仍为 0.30，接触处余量缩小至 0.015 模型单位。已有正间隙仍完全不动。
- 只修正沿该方向最外层的上衣表面，被同件外层挡住的内折/衬里不触发膨胀。接缝处增加微小偏移查询避免射线恰落三角边漏判。重合的 UV/材质接缝顶点共享位移，但不焊接源几何、不增加顶点、不插值权重。保留 Y、索引、UV、权重及未受影响的法线，仅重算接触相邻面的法线。
- 先处理上衣，再让外套衣摆避让下装和上衣。该步骤在内搭收拢/隐藏之后，避免刚放开的上衣又被收回裤腰内。此时允许外套的**下摆**变化，肩领/袖子仍保持已有形状。宽松到足够的衣服、没有实际重叠的短上衣不动。
- 自动处理只覆盖腰口附近：长外套下摆远低于腰部时不自动包裹整条长裙；过大的不匹配仍可能超过位移上限。可关闭自动整理，仅保留手动「下摆张开」。

真实 T 恤配长裙、百褶裙、工装裤，以及不同身高与衣面中部纽扣的回归通过。另有刚高于腰口、极小正间隙保持逐点不变、不同下装所需放量不同、水手短袖配直筒裤不翘边、稀疏采样之间腰扣避让及共享加载器解析搭配值回归。浏览器核验水手短袖/直筒裤正侧面、T 恤/工装裤、旧长裙值 40% 切直筒裤 0%、分别调整/重置/撤销/重做/保存重开，换装时人物 ID 不变。

开衫局部修正另覆盖：高腰接触不改变已外张的低处衣摆、前方接触不移动后片、材质接缝一致、隐藏内褶不触发、真实开衫配水手百褶裙/长裙/宽松短裤。三套衣摆区域超过 90% 顶点不移动，最低下角超过 90% 精确保留；短裤实际接触的少量下角位移小于 0.03。浏览器复核水手内搭与这件开衫的裙装轮廓，并保留 T 恤腰扣的局部避让。仍不是全姿态布料模拟，肩袖原有穿插限制不因本轮衣摆修复消失。

## 开襟穿插与连续换装修复

### 长裙侧边轮廓保护

长裙比短外套向两侧展开，斜向径向查询可能命中外套，却误删实际露在外套轮廓之外的裙面，造成裙边突然被削回去一块。仅对 `lower-long-skirt` 的衣服遮挡增加正背方向覆盖检查：原顶点、面心、边中点都必须同时受外套正背投影覆盖才可删面。原内收、其他下装与外套衣摆参数不变；不扩大外套来掩盖缺口。真实普通站姿下，开衫轮廓之外的长裙缺失采样由修复前 89 处降至 0；另有宽裙/窄外套的构造回归，保留拓扑、UV 与蒙皮权重。

立领制服配半落肩开衫仍有大块深色碎片，原因是横跨开襟的三角面无法整面删除。参考 [Character Creator 5.2 的 Tuck In / Keep Outer](https://manual.reallusion.com/Character-Creator-5/Content/ENU/5.2/04-Introducing-the-User-Interface/Cloth-Layer-Settings.htm) 与 [Conform](https://manual.reallusion.com/Character-Creator-5/Content/ENU/5.2/08-Cloth/Conforming_Clothing.htm)，在遮挡之后增加局部内收。借鉴公开方法，不使用其 SDK，也不宣称复现其内部算法。

- 保留跨开口的整三角面，按衣身前后方向求真实外套表面，只把受覆盖的剩余顶点收进去；横向与高度不变，重新计算法线。原 UV、索引顶点编号、骨骼权重、外套原轮廓均保留，未细分或插值权重。模型内收余量为 0.12，属于本项目参数。
- 只处理衣身与靠肩的 40% 手臂段。前臂和袖口沿用连续袖筒遮挡，避免把外露袖口压扁。领口、手与手指权重保护继续生效。
- 从内收前的服装计算身体整三角面遮挡，尊重每件自动皮肤遮挡开关；身体不变形、不新增顶点。对保留的身体表面再做距离下限检查，内搭至少留 0.018 余量，避免收进后领口皮肤下面。普通鞋袜/手动皮肤遮挡仍沿用原逻辑。
- 正常、叉腰站姿对照中，立领上衣两侧大块穿插明显减少，侧背面与露出袖口保留。肩边的极小残片、不同蒙皮在叉腰时产生的局部缝隙仍可能存在；不保证所有姿态零穿插。

换装不再重新 `buildBody`。`Puppet` 将身体、站姿 mixer、服装拆成独立生命周期，保留骨架、脸、头发、镜头和动画时钟；衣橱预览直接使用所选站姿，取消反复入场。`prepareApprovedWardrobe` / `prepareHoodie` 只创建未挂载的实例；准备成功后同一帧释放旧衣、挂新衣并替换皮肤遮挡/鞋底支持。失败保留旧衣，快速切换丢弃过期结果。`dressApprovedWardrobe` / `dressHoodie` 仍是小屋的即穿入口。

`rig.baseGeometry` 始终指向未遮挡的身体，避免在旧遮罩上再次裁剪。旧卫衣也使用独立身体副本，换到空搭配可完整恢复。换色仍只更新材质。浏览器通过 DOM 中的身体 ID 与帧计数核验换上衣、快速切换、版型调整、切换站姿时身体 ID 不变且帧数持续增长。

### 贴身毛衣 / T 恤的肩领露肤

贴身基础款的顶点没穿进皮肤，并不代表三角面内部也安全。用户截图中的胸口三角碎片与肩领细缝可在普通站姿稳定复现。对源自当前身体表面壳的 `fitted-*` 和 `basic-tee`，在顶点内收后额外检查每个保留三角面的三角点、边中点和重心与可见皮肤的距离。只沿原顶点到原位置的方向减少必要的内收幅度，目标余量 0.018，最多恢复到原衣面；共享顶点的相邻面迭代最多 12 轮。没有新增顶点、插值权重或改身体/外套网格。笔挺立领等非贴身款保持既有整理规则，避免扩大到另一类版型后退回原先穿插。

普通站姿的 T 恤、圆领、高领毛衣肩胸正面射线回归，在修复前分别检出 83 / 90 / 35 个新增露肤采样点，修复后均为 0。该检查使用实际蒙皮后的几何和外套遮挡，另有衣面中心而非顶点穿肤的正背两侧构造回归。浏览器对照确认领口露肤减少；间隙不足时仍可能保留少量内搭边缘，尤其叉腰肩外侧，不能把这个结果当成全部叠穿问题解决。

## 袖筒连续覆盖修复

用户反馈「半落肩开衫 + 长袖水手服」仍有成片白色内搭穿出。相同骨架/站姿对照复现后，确认逐点射线的切线角保护会跳过深褶皱表面，保留下零散内搭三角面；原先把手腕权重一律作为保护条件，也会漏掉实际埋在外套里的衣料。

补查 [Character Creator 的 Cloth to Cloth Hiding Groups](https://wiki.reallusion.com/Content_Dev%3ACC_AHMP_Guide) 后，增加连续袖段的覆盖判断。借鉴的是按服装区域遮挡内层的思路，本项目的区间仍从实际拟合几何计算，不是 CC 的分组数据或 SDK：

- 沿左右手臂绑定轴每 0.025 模型单位采样一个截面，每个截面查询整圈 32 个方向；均命中同侧不透明袖子才接受。使用现有 `three-mesh-bvh`，不另外实现射线引擎。
- 内搭样本前后留有开口余量，邻近截面都成立才算位于连续袖筒内。此处允许深褶皱斜面，不再逐块漏判；袖口外、开缝及透明材质继续保留。区间跟随外套袖长重新计算，不按手腕骨位置硬切。
- 仅对传入的内搭服装生效。手腕权重的**衣料**在确认埋入外套时可以隐藏；颈/头/手指仍保护，素体手掌/手指和蒙皮完全不改，外套原顶点不改。
- 仍删除整三角面，保留原 UV、法线、权重与所有可见袖口。没有引入薄壳边界的新顶点插值。

实测同一套水手服/开衫：袖部零碎白块消除，普通/叉腰/可爱站姿的正、侧、背面检查通过；袖长 70% 时内搭外露前臂保留。西装与连帽外套的对照保持原有结果。新增深褶袖筒、手腕权重衣料、开缝/透明跳过、短袖段及真实水手服资产回归，合计 30 项相关测试通过，衣橱生产构建通过。采样不是任意微小镂空或所有动画下的碰撞证明，肩领和袖口跨边界的面仍保守保留。

## 先查成熟方案

### 动作中穿模与露肤缺口复查（2026-09-22）

用户报告自然待机时立领上衣穿出开衫、腿有白线及皮肤消失。使用同一套「立领制服 + 开衫 + 水手短裤 + 初始长袜/便鞋」对比完整搭配、去袜、去鞋、恢复完整皮肤四种状态，并与普通站姿对比。

- **已修：身体遮罩边界裂缝。** `createClothingMask` 原来递归细分遮挡边缘，分别平均位置和权重。在 LBS 下，新顶点的变形不等于原三角面上对应点的变形；只细分一侧又形成 T 接点，弯腿后会露出背景。现在 `prepareApprovedWardrobe` 的身体、袜子/靴筒裁剪均保留边界整面，只去掉完全覆盖的原面，不新增顶点或权重。对照帧腿部细线消失；新增实物动作回归检查保留皮肤与原身体在多个动画时刻完全重合。
- **已修：初始鞋袜内侧开口。** 源鞋袜的左右腿原本相接，按腿拆开后每条腿留下 15 条边的内侧缺口和 4 条边的鞋底缺口，站直时互相遮住。`closeFootwearSeams.ts` 用 Three.js 自带 Earcut 对这四圈 YZ 边界封口，共增加 30 个三角面；原顶点、权重、外部轮廓及两圈袜口保持不变。重新发布 `original-outfit.glb`，袜子 473 面、鞋子 226 面；原始 JSON 与卫衣形状不改。真实动画对照中，穿鞋/脱鞋的内侧缺口消失。
- **新增：随姿势更新的内搭修正。** `garmentMotionFit.ts` 复用现有 `three-mesh-bvh` 的蒙皮几何生成与 BVH refit，在移动的胸骨坐标系内查询不透明外套。保留的宽松衬衫/水手服躯干和肩根发生穿插时，局部调整衣料深度，再经该顶点混合蒙皮矩阵的逆回到绑定空间。`updatePose()` 同时接入衣橱预览与小屋，每帧从固定基线求解，不累积变形；换衣、关闭整理、销毁资源沿用现有实例生命周期。

动态约束细节与验收：

- 只处理配置为 `loose-shirt` / `sailor-shirt` 的内搭，绑定空间范围 x ±0.85 × 身高、y 2.05–3.4 × 身高；单顶点最大位移 0.32 × 身高，接触余量 0.025 × 身高。前后射线在胸部中心平面前停止，不把开襟后的背片当成前方覆盖。跨开襟三角面的中心顶点受保护，前臂与自由袖口不进入约束。
- 顶点和面心先检测，接近外套的三角面才补充边中点/内部样本；同一帧只查询一次，再进行六轮纯数值约束。不在每轮重复查 BVH，不在每帧重新加载衣服。骨姿不变时跳过；保留未受影响的原法线。透明、镂空和图片材质保守跳过。
- `utils/garmentMotionFit.test.ts` 通过正式加载入口，验证普通站姿与四段动作、重复时间不累积、角色旋转/平移/缩放不改变局部结果、外套/索引/UV/权重/身体保持、自由袖口不变、脱下恢复和源缓存隔离。胸骨坐标系前侧采样：普通 55→1，自然待机 160→15，轻轻待机 55→1，轻声交谈 51→0，转身手势 31→3。只代表所列时刻与躯干区域，残余边角仍存在。
- `utils/closeFootwearSeams.test.ts` 检查 38 条内侧开放边全部闭合、原顶点/面保留、两圈袜口原样、左右腿不重新相连。鞋袜裁剪测试改为验证原三角面和权重保留，而不是要求新插值边界落在固定高度。
- `wardrobe:check --all` 增加以上回归及动作皮肤回归；369 组搭配的姿势采样也实际调用 `updatePose()`，不再只检查绑定姿势的整理结果。检查报告仍区分数据有效性与视觉提示。
- 浏览器对照看正、侧、背面及去鞋/去袜；轻柔与转身动作有改善，主页面仍保留原搭配与人物。当前机器自然待机 100 个时刻的热态修正中位约 14 ms（单次加载与渲染不包含在内），复杂搭配仍有计算成本，不承诺所有设备固定帧率。

## 新衣服接入与增量验收（2026-09-22）

`apps/room3d/chibi/wardrobeLayering.json` 是叠穿结构的登记表，包含可复用的 `profiles` 和每件服装的 `garments` 引用。所有 38 件已发布服装都已登记。新增衣服必须按实际结构选择配置，不能根据名字猜测：

| 配置 | 用途 |
| --- | --- |
| `sailor-shirt` | 宽水手领折叠 + 固定姿势肩袖/背腰整理 |
| `loose-shirt` | 衬衫共用姿势整理，保留原领型；身体不做薄壳边界细分 |
| `surface-top` | 贴身壳上衣，三角面内部皮肤距离保护 |
| `generic-top` / `surface-onepiece` | 常规内搭整理；后者保留薄壳身体表面 |
| `posed-outer` / `surface-outer` | 对上述宽松衬衫执行姿势收尾；后者保留身体表面 |
| `generic-outer` | 保留开衫已有整理方式 |
| `narrow-bottom` / `wide-bottom` | 接入检查选择宽窄下装代表；实际放量仍查询真实几何 |
| `long-skirt` | 裙边正背轮廓保护，不削掉外套轮廓之外的裙面 |
| `separate` | 鞋袜、配饰、头饰沿用各自流程 |

`wardrobeLayering.ts` 供运行时读取，替代肩领、贴身上衣和裙边处理中按 ID/前缀判断的分支。同类新衣只需引用配置；未知配置不会自动启用特殊折叠，目录校验会报错，发布脚本也拒绝未登记的衣服。原有开衫/帽衫局部皮肤遮罩、鞋袜接缝等资产专用规则仍保留，并非所有适配都已通用化。配置是制作时的结构声明，不是自动识别模型，也不是通用布料模拟。

接入新衣后运行：

```powershell
pnpm wardrobe:check collar-shirt
pnpm wardrobe:check hood-parka original-shoes
# 修改共用叠穿算法后运行完整接入检查
pnpm wardrobe:check --all
```

命令使用现有 Vitest、正式 GLB、当前 48 骨素体和正式换装入口，不启动浏览器、不修改用户搭配。`wardrobeCheckPlan.ts` 按当前目录动态选组合并去重：新增上衣检查所有外套及宽/窄/长裙上下文；新增外套检查各类代表内搭、下装和连体衣；下装检查代表上衣、所有外套与鞋；鞋袜检查相互遮挡。每件也检查单穿。`--all` 同时运行既有的十个服装回归文件和目录/计划检查；只改配色无需运行这套几何检查。

输出 `output/wardrobe-check/latest.md` 与 `latest.json`，每次覆盖上一份报告。当前检查普通站姿、自然待机，以及两个已退役且仅用于测试的叉腰/可爱压力姿势，各取 0.7 秒；检查有效蒙皮坐标、几何索引、上衣/外套/下装/连体衣的 UV 和权重保留、脱衣恢复及关闭整理后的源缓存一致性。数据失败返回非零退出码。外套搭配另做正背/右侧躯干射线采样；采样提示和完全被遮挡的部件列为优先视觉复核，不作为已确认碰撞，也不让整个命令失败。历史三姿势报告保留原有计数。

**这份报告不是视觉验收通过证书。** 正常露出的领片可能触发提示，无提示也可能漏掉细小穿插；默认身高/默认版型、有限角度及静态站姿不能覆盖全部动作。长裙轮廓、下摆、鞋袜、透明贴图、配饰仍须制作阶段看图。报告对每个组合保留“待看图”状态，开发者负责完成验收，不把检查工作塞进玩家换装流程。原有定量几何回归（肩胸露肤、裙边缺口、下摆局部变化等）继续单独运行，不能被本报告替代。

## 数据与实现

### 背面与腰侧收尾（2026-09-22）

后续衬衫复查发现：穿着姿势校正原来只接了水手服，翻领衬衫仍仅走绑定姿势检查，导致大衣肩部及腰侧碎片。现将 `fitLayeredUpperGarments` 的共用肩袖/背部/腰侧收尾接到 `collar-shirt`、`stand-collar`，复用同一套几何查询；只有水手服执行宽水手领的专用折叠，不能把这种折叠套给衬衫。仍明确限定已验收的宽松上衣和三件外套，贴身薄壳、透明外套及开衫保持既有保护。新增两件衬衫 × 三件外套的正背面，以及大衣叉腰/可爱站姿回归，同时验证原袖口、外套、UV/权重和脱下恢复。测试的背片采样排除独立袖口网格，不能把弯臂后挡在身体前面的正常外露袖口当成穿模。

水手服的专用内收移到通用遮挡和下摆避让之后：旧顺序会让下装避让重新把已收进外套的衬衣腰角撑出来。沿固定试穿姿势下外套的实际水平截面收拢背部与腋下，再检查背领中央和肩部表面；前侧开襟平滑退出，原长袖末端不参与此约束。继续使用原顶点及权重，不扩大大衣或修改下装。透明外套和半落肩开衫保持原规则。

新增六组正式资产背面采样（两件水手服 × 三件外套，都搭长裙），范围 x ±0.60、y 2.38–3.30、步长 0.012。沿背面射线检测内搭先于外套出现的采样数，长袖的连帽/西装/大衣原为 0/75/231，短袖原为 0/33/368；收尾后六组均降至不超过 1。此指标针对普通站姿指定区域，并不意味着全姿态布料碰撞为零；叉腰等姿势仍须视觉检查。补充对已被外套背面完整覆盖的内搭整面遮挡，避免跨胸骨/手臂骨边界的布片在叉腰时翻出；只有三角形的角点、中点与中心全部通过才隐藏，中央前襟保留。另有大衣长短袖 × 叉腰/可爱站姿的四组背面回归，采样排除正常外露的前臂袖口。正面开襟、原袖口、原外套位置、UV/权重、关闭后恢复和活骨架不变的既有回归继续保留。

- `approvedClothing.ts` 先加载、重绑并应用版型，再按需加载 `garmentLayering.ts`。外套是遮挡层，当前上衣/连体/下装是内层；鞋袜现有处理保持独立。
- 在共用绑定空间计算，骨骼位置来自 inverse bind；不会根据切换时恰好播放到的姿势生成不同结果。躯干射线从身体轴出发，袖子从对应手臂骨段出发；外层三角面的骨骼归属须匹配。
- 三角面的三个顶点、三个边中点、重心都通过覆盖检查才隐藏。袖部先检查上述连续覆盖区间；其他位置检查四个邻近方向，留出领口、袖口、衣摆及开襟余量。普通射线仍保护颈、头、手和手指权重较大的区域。
- 允许外套在径向上位于内搭以内，这是消除穿插所需的层级判断；限制距离、部位和切线角，避免把远处或其他肢体当成覆盖。当前距离上限为模型单位 0.65，开口余量为 `0.045 × min(1, bodyHeight)`，均是本项目实测参数，并非上述产品公开的参数。
- 外层透明、alpha test、alpha map 或含图片贴图的材质保守跳过。当前四款外套均可按不透明几何检查；未来透明/镂空外套需要补逐像素透明度判断。
- **遮挡只删除实例索引中的整三角面**，局部内收只改内搭实例的位置/法线。不新增顶点，不插值蒙皮权重，不修改外套的顶点/法线/UV，不改缓存源资产。分组保留材质索引，换装/关闭从源几何重建，资源跟随服装实例释放。
- `Puppet` 回传实际整理结果给 `WardrobePicker`。只换颜色仍仅更新独立材质，不重复裁剪；关闭整理不会清除配色或版型。

## 适用范围与验收

这是辅助消除衣服穿插，不是布料碰撞模拟或全姿态保证。明显超出外套的领片、长袖口等应继续显示。连续袖筒修复处理袖部成片漏判，跨开口的大三角面保留并局部内收。不同蒙皮在极端动作下仍可能产生新的穿插或暴露遮挡边界。若继续优化这些情况，应增加资产遮罩/匹配版型或制作 cage，而不是直接扩大裁剪范围、细分后重新插值薄壳权重。
