画质面板可切换「原始 / 复古」，默认复古；本机偏好 `sully-home3d-furniture-style` 不写入角色布置。复古风格下提供「家具描边：开 / 关」，默认开启，本机偏好 `sully-home3d-furniture-outline` 保存；关闭直接跳过遮罩和合成绘制，保留复古配色与白色反光，不重建家具或写入角色存档。仅家具实例使用简化明暗和克制白色反射高光的着色，保留原部件颜色、法线、透明裁切和自发光；房壳、建造墙体与角色沿用原渲染。没有降分辨率或像素滤镜。家具整体可见轮廓加约 0.65 CSS px 的紫灰细边，使用合并遮罩避免描出各零件内部接缝；外围光晕已移除；表面白色反光取实际光源及视角的镜面分量，粗糙度 0.42，白色混合上限 18%，不使用全屏 bloom。程序实现见 `apps/room3d/furnitureStyle.js` 与 `furnitureHalo.js`，后者增加一次遮罩渲染与一次透明合成，随主循环按需绘制，卸载释放目标纹理及材质。

## 源文件与生成

`art/jellyfish-home/export_kit.py` 从已有 Blender 场景提取模块，按资产内的材质合并静态几何，保留水母动画节点。输出 `public/room3d/kit.glb` 和 `catalog.json`。Blender 是资产制作端，Three.js 是实时显示与交互端。

目录中带 `url` 的家具使用独立 GLB，加载时按目录宽度归一化并将底部对齐地板，继续共享模板几何和材质。导出器保留这些外部条目和文件，避免重新生成 kit 时丢失沙发。

`apps/room3d/model.js` 管理纯数据和碰撞约束；`editor.js` 管理渲染与编辑；`Home3DView.tsx` 连接 React 生命周期和角色保存。

## Chibi 入住

`apps/room3d/chibi/` 复用发片小人的 FBX 素体、原图分层与动作。`Home3DView` 优先读取 `chibiStudio.room.state`，没有时读取 `vr.state`，并解析本机自定义部件。隔离捏人器渲染副本还原选件与配色，禁止草稿写入；上传的单张成图没有分层，需先在手办柜保存一套形象，不自动随机替换角色。

小人与家具共用 renderer；进入当前房间时根据家具的碰撞盒寻找空地，总览隐藏小人。满房无空位时提示收起家具。动作面板提供两款挥手、睡觉、生气和晃动；省电档手动动作播放 4.4 秒后停绘，均衡/清晰继续播放，减少动态效果仅展示静态姿势。点击空地可寻路移动，「小人」面板提供当前所在区域的门通行按钮；暂不自主跨房间选择活动，动作和行走位置不写入房间存档。

「小人 → 找个位置坐坐 → 花瓣双人沙发」将小人放入已校准的左/右坐位，单人款居中；仅最底下左右脚尖稍微前伸，下半身保持原形，小手刚性平移/旋转。`catalog.seats` 保存家具局部支撑面坐标与朝向，`seating.js` 跟随实例平移/旋转；`visitor.seatOffset` 按坐姿实际下表面校准，避免腿脚埋进坐垫。动作与姿势分开：挥手、生气、晃动、打瞌睡保持坐位，「坐好」回到安静坐姿，「站起来」才回地面；收纳、移除座椅或切换房间释放坐位，总览暂时隐藏。坐位占用属于临时状态，不保存为外观或布置。当前只支持一只小人手动试坐；未配置坐位的旧椅子不自动套用。

3D 发片支持「贴头包裹」和「向外伸出」。后者保留完整画布的 x/y 坐标及顶部轮廓，只添加浅弧度，不沿头壳收拢。`chibi/types.ts` 的 `builtinHairModes` 按具体素材 ID 标记已核对的发髻、马尾、猫耳；手动 `assetModes` 优先于内置分类，不按 back2 整栏套用。额外上传发片的分类随该层保存。3D 调整提供 40 步撤销/重做，滑杆单次拖动合并为一步；全部重置清除尺寸、手动分类和额外层，恢复内置默认，可以撤销。选件本身仍由原生捏人器管理。

伸出发片支持 `puff`：透明轮廓的距离场控制前后两面，中间鼓起、边缘收薄，独立的啾啾分别归一化；透明区不填充。`offsetX` / `offsetZ` 为所有发片提供左右、前后平移。捏人器的隔离副本还提供选件与配色的撤销/重做，不修改原始 2D 捏人器文件。

面板保留「前后位置」，移除「离头距离」滑杆；旧距离参数及额外层的默认外圈间距仍保留以兼容已有外观。衣服 / 外套在合成前分别从各自不透明上沿调整长度（0–2），不再提前合并；未覆盖区域以肤色打底，背面只延续有衣料的行。`test/fixtures/chibi-clothing.html` 验证独立长度、前后露肤与零长度。

小人素体按材质合并索引分组，避免每个三角形单独绘制。3D 捏人预览复用 WebGLRenderer，静止停绘、动画最高 30 帧，缓存补片取色与透明轮廓距离场；编辑时暂停背后的房间。`test/fixtures/chibi-performance.html` 检查静止帧数、调参画布复用和绘制提交量，当前测试形象为 21 次提交（不代表所有造型或设备帧率）。

`chibi-experiment.html` 直接预览组合场景。「捏小人」包含原生选素材与 3D 调整页签；切入 3D 时捕获当前编辑的分层，不重新随机。四种头发分别调长度、宽度、上下位置与离头距离；最多六层额外发片可以复用后发或上传透明 PNG/WebP，并作为完整外圈薄层渲染。确认后将调整应用到房间，实验形象与参数分别保存到 `chibi-world-experiment-appearance` / `chibi-world-hair-settings`，暂不写入角色正式存档。`test/fixtures/chibi-layers.html` 检查原生 Roll 与 savedState 还原后的各层一致性；房间测试包含初始家具空地及满房拒绝落点。

独立预览：运行 `node art/jellyfish-home/editor-build.mjs`，再运行 `node art/jellyfish-home/server.mjs`，打开 `http://127.0.0.1:4178/assets/editor.html`。预览存储与应用角色数据分开。

## 渲染预算

### 柔和日光微调（2026-09-16）

基础照明保留三盏灯：暖色定向主光从开放侧斜照，略降均匀环境补光，冷色补光移到正面侧方。扩大主光阴影相机以覆盖放大后的当前房间，降低法线偏移改善家具接地；桌面清晰档使用 2048 阴影，均衡/触屏保持 1024，模糊半径随分辨率同步以保持柔软程度。切档释放旧阴影目标，继续按需更新缓存。小人维持不投射/接收自阴影及原有轻微自发光，避免发片压黑脸。设置选择不被覆盖，省电档仍关闭阴影，总览沿用轻量显示。

窗户采光另用固定两盏可复用聚光灯池：清晰桌面最多两扇外窗，均衡/触屏最多一扇，省电/总览关闭。`windowDaylight.js` 负责真实外墙和同层细绘区域筛选、朝向及房间坐标换算；`windowDaylightLights.js` 共享一张 128² 程序四格遮罩、每灯 512² 缓存阴影。家具/窗户拖动或布局变化时更新遮挡，静止不刷新阴影；无逐帧创建资源，无额外后处理。内墙窗不产生室外日光；显示隐藏墙面不会关闭物理存在的外窗光。卸载时释放灯池阴影和遮罩。

### 手机端容量

手机浏览器每个角色最多 5 块原始房间面积，每块摆放最多 15 件家具。拆墙合并不减少面积块数；按物件中心落在哪块原始地板计数，不能用桌椅/台面父子归属绕过单区限制。桌面摆件与吸附椅子各算一件，收纳物件、墙段及边界门不计入 15 件；原有存档最大容量仍作为结构安全上限。桌面端沿用原有容量。

`deviceBudget.js` 统一计数和限制；新增、复制、套装、恢复、跨区拖动及导入都会检查，整组超限原子回退且不写历史。旧超限布置加载时不删除、不截断，可以继续收纳、搬走或改色，但超限区域不能进一步增加；导入新布置须完整符合手机额度。撤销/重做保留原历史状态。家具架/扩建/房间/装扮显示已用额度。

手机省电档默认仅精细显示当前一间，均衡/清晰按档位预算；保留正在行走/互动所在区域，静止停止绘制，同层骨架保持可见。手机检测依据移动设备标识，或小屏粗指针设备，桌面窄窗口不自动套用手机额度。数量限额不等于帧率保证：面数、材质提交、小人发片和设备性能仍有影响，模拟浏览器测试不代替真机发热/帧率验收。

### 分房间地板与壁纸（2026-09-16）

「装扮」可直接选择同层房间，每间分别保存 `floorStyle` 和 `wallStyle`；缺省保持原木拼板/素色墙。地板支持细木、方砖、双色格与素色，壁纸支持条纹、圆点和半墙护板；沿用各房的 `floor` / `wall` 配色和撤销重做、导入导出、刷新保存。房间主题按钮只影响当前房间。拆墙合并保留原区域各自装修，恢复隔墙仍分别显示各侧壁纸。

`finishes.js` 验证样式并沿真实墙段/门洞计算内侧饰面，隔墙两面归各自房间，栅栏不糊壁纸，门叶不覆盖；三种墙面显示模式照常生效。`finishMeshes.js` 使用数学纹样和共享标准材质，每段仅少量三角面，无图片、纹理或逐帧生成；纹样坐标使用房间实际尺寸。重建释放旧饰面几何与闲置材质，远处房间仍保持自己的装修颜色/样式。独立验收入口 `room3d-finishes.html` 与 `finishes-qa.mjs` 检查双色相邻房、拱门、拆墙、无墙、保存/历史、手机滚动和资源回收。

2026-09-13 更新：默认使用省电档，画质设置保存在当前设备的 `sully-home3d-quality`，不跟随角色导出。省电 / 均衡 / 清晰的像素倍率上限分别为 0.75 / 1 / 1.5。省电关闭阴影与动画，总览只细绘一间；均衡细绘两间，清晰触屏两间 / 桌面四间。省电与其他静态场景在相机稳定后停止 RAF 调度，操作、尺寸改变或页面恢复时唤醒；以下此前预算以对应开启效果的档位为准。

装扮支持整屋主题及独立墙面、边框 / 底座、地板颜色（`wall`、`trim`、`floor`）。布置模式提供 45° 视角按钮及拖动视角切换，切换到视角模式时不拖动家具。

交互修订：取消独立的拖动视角模式。点击家具选中，再拖选中家具移动；拖其他区域转视角，滚轮 / 双指缩放，右侧常驻缩放和 45° 转向按钮。双指接管时取消单指家具拖动，避免误放。选中只显示底部约 106px 的工具条和底部轮廓，色块按需展开。顶部提供撤销 / 重做，快捷键 Ctrl/Cmd+Z、Shift+Ctrl/Cmd+Z 或 Ctrl/Cmd+Y。家具修改不重置镜头，关闭镜头惯性方便精确摆放。

- 默认视图显示当前楼层的所有房间骨架，隔墙关闭也可同时看到相邻小屋；家具按画质至少细绘最近三间，额外保留小人行走所在房间及当前活动使用的家具房间。连通区域再大也不绕过预算，远处区域复用简化地板，切换房间、走近或开始互动时补全家具；总览按画质预算细绘家具，其余区域使用共享的简化地板及真实边界。
- 静态家具子网格冻结局部变换矩阵，根节点仍可移动/旋转；动画节点、赛车方向盘、音游按键保留更新。素材查找使用索引，同一拖动落点不重复计算；碰撞先筛去包围盒不相交的家具，再检查细分碰撞盒。
- 实例共享几何与同色材质；重建时清理闲置材质及连接块资源。卸载释放渲染器、阴影、几何和纹理，并取消加载及动画循环。
- DPR 上限 1.5，触屏绘制上限 30 帧 / 秒，桌面上限 60 帧 / 秒。这个上限不是实际帧率保证。
- 仅单间使用缓存阴影，布置变化时更新；总览关闭阴影和呼吸动画，静止时不重绘。
- 页面隐藏时停止绘制；系统减少动态效果开启时，单间也按需绘制。

## 桌椅吸附（2026-09-16）

- 椅子拖到桌边的空闲坐位附近（0.65 格内）自动对齐并朝向桌面；新增椅子优先寻找合法空位。电脑桌配猫耳椅沿用键盘与坐姿校准，圆茶几/雏菊桌支持四侧。桌位有占用或空间不足时不强行吸附，双人沙发、电视柜、储物柜不自动组成桌椅。
- 拖桌子会带上吸附椅子及所有桌面物件；选中吸附椅子旋转时改为整组旋转。直接拖开椅子即可解除，或用「关闭吸附」单独精调。全组落点统一检查越界、墙体和家具，失败整组回退；跨已打通房间、整组收纳/恢复、撤销重做和刷新均保留关系。
