# 2026-10-29 社区反馈修复

基于 `origin/master` 的 `c5bacfb4`，在独立工作区 `codex/community-fixes` 实现。原本正在开发的本地目录不参与改动。此次不改 APP_VERSION。

## 已实现

1. 私聊加号面板末页新增「导出记录」：TXT、User / AI 前缀、每条消息原始时间，包含已归档对话，正文不清洗；排除系统提示、隐藏消息及其他场景记录。图片等用类型占位，不把媒体二进制写进文本。
2. 见面记录从全量 `source=date` 记录排序，修复 500 条窗口导致旧记录不可见的问题。按次／按日期均可折叠，提供年月筛选与日期定位；跨月的同一次见面可以在两个月找到。慢请求在退出或切换入口后不得重新打开历史页。
3. 见面／剧情制作器增加 CSS 编辑、AI 提示词、即时样例预览和保存。基础样式切换保留自定义 CSS，文件往返、应用和美化分享服务均保留该字段；「无」停用美化。
4. 银行与生活记录增加收入，角色可区分支出和已到账收入并代记。旧账仍算支出；收入不参与支出预算及结余奖励计算。统计支持指定月份和全部记录，CSV 分为当前范围／全部，保留小数、类型、时间、备注、分类。
5. 捏人器忽略重置产生的空草稿，重新打开可恢复已保存形象；增加显式「已保存形象」按钮，完整恢复选件、换色与翻转，且不自动确认修改。520 用户编辑入口补传完整 savedState。

## Anthropic 原生接口补充

根据后续确认，已增加全局／角色 API 的「Anthropic 原生」类型、预设保存、Messages 请求／响应与流式 SSE 转换，以及自动 Prompt Caching。调用记录展示缓存读取与写入用量。覆盖 safeFetchJson 和裸 fetch，不另建代理。

amsg 共用同一转换器，既有加密凭据结构保持三字段，定时与即时对话均已通过真实 Worker 模拟。发布后沿用冷启动自动更新，完成后自动复查能力，无需手动重连；首次原生请求也会复查旧的不支持结果，仍未确认支持时阻止提交云端任务。

官方无密钥 CORS 预检返回 200 并允许所需请求头；没有真实 Key，未进行实际付费生成或缓存计费验收。配置方法、实现边界与验证见 [Anthropic 原生接口说明](../docs/anthropic-messages.md)。
