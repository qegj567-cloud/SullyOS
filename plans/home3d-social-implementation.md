# 多人家园执行与验收清单

沿用公共哔哔；不再要求生活圈。同场事件共享，个人上下文、世界书、记忆和水位独立。当前默认逐角色调用，不合并私聊。

- [x] 每位在场角色有独立本地活动状态；移动、座位和互动避免抢占。
- [x] 通讯录按真实角色 ID 读取有向关系；陌生、单向亲疏、拉黑不混淆。
- [x] 邀请名单可恢复；离场取消未完成行为，后来加入者不收旧事件。
- [x] 用户发言后在场角色逐个回应；每轮有限，不无限互相触发。
- [x] 发言、实际动作按正确作者进入共同事件，各人分别记忆。
- [x] 日程可提出串门；房主下一次主请求处理；到时未处理自动同意。
- [x] 到场检查房主、访客、时间和容量；到期离场；关闭页面不伪造离线经历。
- [x] 页面提供来访状态和手动处理入口；错误可见、可重试。
- [x] 自审竞态、删除角色、刷新重入、资源释放、反冒充与上下文隔离。
- [x] 自动化与交互验收，记录完成范围和已知限制。

实现及边界见 [多人家园与串门](../docs/room3d-social.md)。
