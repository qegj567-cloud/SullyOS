# ElevenLabs 实时语音实施与验收

用户已确认：边生成边播放、文字增量转语音、同步字幕、多人整段配音、长文连续朗读。高级音色管理不在本轮目标内。

## 当前证据

- `safeApi.ts` 已支持 SSE `onDelta`；全局默认 `stream: false`，聊天有增量预览。
- 电话传递 stream 配置，但只消费最终 completion。见面和聊天语音都等待完整 Blob。
- 起点：Worker 透传响应流；Vercel 代理整包缓冲；开发代理只支持单人 MP3。现已三处一起扩展流式时间戳和 Dialogue 路由。

## 实施方案

1. 新建共用 PCM 流播放与字幕时间轴：24 kHz 单声道 PCM 分块排程、取消和播放时钟、最终 WAV 保存。请求不自动重试已播内容、不自动切模型。
2. HTTP 时间戳接口经现有代理透传 NDJSON；支持单人、多人和 request-id 暴露。统一解析上游错误、分块边界与中止。
3. 长文按自然句/段拆分，保留完整 Audio Tags / IPA，按官方上限分批，串行上下文衔接；不截断用户文本。
4. 接入聊天、见面和电话的现有播放入口，字幕跟随真实音频时钟；保留完成后的收藏/重播/下载。
5. 电话利用现有 SSE 增量按完整句提前合成；仅有正文才送声音，过滤思考与动作指令。非流式文字接口明确等台词完成后启动音频流。
6. 多人配音从现有群聊记录选择台词与音色，使用官方 dialogue 接口生成整段，提供播放、停止和导出。

## 验收清单

- [x] 第一块音频在上游结束前进入播放器；播放按顺序，无丢样/重复。
- [x] 停止、换角色、退出、错误均取消请求和已排程声音。
- [x] SSE 尚未结束时首个完整句已合成/播放；最终结果不重复读。
- [x] 字幕来自官方 alignment，以播放时钟推进，缓存重播仍同步。
- [x] 多人真实入口、音色校验、Turbo 能力限制说明、整段导出。
- [x] 超长中文/英文/标签/IPA 均完整分段并连续播放。
- [x] 模拟网络、组件/浏览器验收、回归测试和生产构建。
- [x] 文档记录代理更新要求、PCM/WAV 变化、未实测项与官方限制。

## 验收记录

- 132 项相关测试通过（15 个文件），覆盖新流传输/播放器/生命周期、已有 TTS、电话格式、视频口型、见面提示与语音规则。
- 生产构建通过。全仓库 TypeScript 检查仍有已有问题，本次涉及文件未出现诊断；不能称全仓类型检查通过。
- 浏览器使用独立 Chrome、390×844 手机宽度、真实 WebAudio + 模拟 PCM / SSE，不消耗 ElevenLabs 额度。
- 单句：第一帧在响应 EOF 前进入 WebAudio；SSE 思考内容未送入合成。实际电话首句早于文字结束约 2 秒启动，最后三句只播一遍；这是模拟服务时序，不是线上延迟指标。
- 聊天：首次点击有同步字幕；离开再进入后持久缓存重播，新增请求为 0。
- 见面：阅读模式会发送整段台词与叙述；点击停止后模拟上游 cancel=1、openAudio=0。
- 群聊：选择两条角色消息，从真实入口完成多人配音。导出 WAV 可解析：单声道、24 kHz、16 bit；对应两块模拟 PCM，共 21600 样本。
- 代理断开浏览器时取消闲置上游 reader；旧 Worker 返回 MP3 会明确提示更新代理。
- 浏览器模拟长文 2160 字，两个请求总计恰好 2160 字；模拟 402 只发一个 v4 请求，没有重试或切模型。
- 截图与测试 WAV 在忽略目录 `output/playwright/`，不提交生成物。

未验证：真实上游音色、时间戳精度、账号套餐/Voice ID 权限、iOS/Android 真机行为。中心 Worker 和生产前端尚未部署。用户验收时应先同步代理版本，再用实际账号试听；不能把模拟测试当真实 API 验收。
